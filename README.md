## 系统特点

- **三层记忆架构**：情景记忆 → 语义记忆 → 强制规则，知识持续沉淀
- **智能内容分诊**：自动分类新输入到 6 个方向
- **任务追踪系统**：时间意图自动捕获，每日简报提醒
- **标准化输出**：统一的内容格式，支持多平台发布
- **中文排版规范**：内置中文文案排版规则，提升内容专业度
- **自我迭代机制**：系统会随使用不断进化，越用越聪明

### 自我迭代：系统的核心能力

```
使用过程 → 发现问题 → 提炼模式 → 沉淀规则 → 自动执行
                ↓
         三层迭代：
         ├─ 操作层：单次改进
         ├─ 方法层：知识沉淀（语义记忆）
         └─ 系统层：规则固化（强制规则）
```

**示例**：
- 第 1 周：AI 总是忘记中英之间加空格 → 用户纠正 3 次
- 第 2 周：创建 `00-typography.md` 规则
- 第 3 周起：自动执行，零纠正

> 系统不是静态的，而是随使用不断进化的。每次使用都是学习机会。

## 快速开始

### 1. 环境准备

**系统要求**：
- macOS / Windows / Linux
- 16GB+ 内存（推荐）
- Node.js 18+

**安装 Claude Code**：

```bash
npm install -g @anthropic-ai/claude-code
```

### 2. 安装本模板

**方式一：直接下载**

```bash
# 克隆到你的主目录
git clone https://github.com/yourusername/AI-Second-Brain.git ~/AI-Second-Brain

# 或使用 GitHub 模板功能
# 点击 "Use this template" → 创建你的仓库 → 克隆到本地
```

**方式二：手动创建**

1. 复制本模板的所有文件到你的工作目录
2. 重命名目录（建议：`AI-{YourName}`）
3. 修改 `CLAUDE.md` 中的名称

### 3. 首次启动

```bash
# 进入目录
cd ~/AI-Second-Brain

# 启动 Claude Code
claude
```

在 Claude Code 中输入：

```
启动 AI 助手
```

系统会自动：
1. 加载 `rules/` 目录下的所有规则
2. 读取 `任务清单.md` 中的未完成任务
3. 输出今日简报
4. 询问：「今天有要分诊的内容吗？」

## 核心功能

### 1. 智能内容分诊

当有新的文章、想法或链接时：

```
你：今天有要分诊的内容
AI：请粘贴内容
你：[粘贴内容]
AI：已分诊到 01-内容生产/，类型：A类（高适配）
```

分诊方向：
- **01-内容生产**：可发布的内容
- **02-项目**：业务/工作项目资料
- **03-学习**：学习资料、研究
- **04-个人成长**：个人思考、灵感
- **05-稍后处理**：暂时无法分类
- **06-归档**：无需处理的内容

### 2. 任务追踪

自动从对话中提取任务：

```
你：我需要下周完成这份报告
AI：已创建任务：「完成报告」，截止日期：下周
```

每日启动时自动输出：
- 今日日期
- 紧急任务（P0）
- 近期截止（未来7天）
- 已过期任务

### 3. 中文排版规范

所有中文输出自动遵循：
- 中英文之间加空格
- 中文与数字之间加空格
- 数字与单位之间不加空格
- 使用全角中文标点

示例：

```
✓ 正确：在 GitHub 上，我花了 3 天时间完成了 100% 的任务。
✗ 错误：在GitHub上，我花了3天时间完成了100%的任务。
```

## 个性化配置

### 修改系统名称

编辑 `CLAUDE.md`：

```markdown
# 修改前
你是 **AI 助手**，用户的 AI 数字分身。

# 修改后
你是 **AI_{YourName}**，{YourName} 的 AI 数字分身。
```

### 添加你的方法论

在 `记忆库/语义记忆/` 中添加你的：
- 写作风格指南
- 决策框架
- 工作流程模板
- 领域专业知识

### 自定义规则

在 `.claude/rules/` 中添加你的规则文件，命名格式：

```
{序号}-{名称}.md
```

例如：`05-custom-rules.md`

## 工作流程示例

### 场景一：管理新想法

```
你：启动 AI 助手
AI：今日简报... 今天有要分诊的内容吗？
你：有，我想写一篇关于 AI 的文章
AI：请详细描述你的想法
你：[描述]
AI：已分诊到 01-内容生产/，创建文件夹：2026-03-18-AI文章/
```

### 场景二：追踪任务

```
你：记得周五前给客户发邮件
AI：已创建任务：「给客户发邮件」，截止日期：周五，优先级：P1
```

### 场景三：查看进度

```
你：启动 AI 助手
AI：今日简报：
    - 紧急任务（P0）：0 个
    - 近期截止（7天内）：2 个
      1. [ ] 给客户发邮件（周五截止）
      2. [ ] 完成周报（明天截止）
```
