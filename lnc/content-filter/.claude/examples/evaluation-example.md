# 使用示例 / Usage Examples

## 示例 1：小红书内容评估

### 输入

```
请评估以下内容：

【目标平台】小红书
【品牌定位】专业护肤博主，理性种草风格，强调成分分析
【内容草稿】

姐妹们！我发现了一个宝藏成分！

最近疯狂研究烟酰胺，发现它真的是全能选手：
✨ 美白淡斑
✨ 控油收毛孔
✨ 抗老抗氧化

但是！浓度很重要！
- 2-5%：日常维稳
- 5-10%：进阶抗老
- 10%以上：刺激风险增加

我自己用的是XX品牌的5%烟酰胺精华，一个月下来肤色确实提亮了，毛孔也有改善~

⚠️敏感肌姐妹建议从低浓度开始，先建立耐受！

#护肤成分党 #烟酰胺 #美白精华
```

### 评估输出

```
## 评估报告

### 综合评分：7.8 / 10
**决策：✅ 过审（建议优化）**

---

### 维度评分

| 维度 | 分数 | 信号 | 说明 |
|-----|-----|-----|------|
| 品牌一致性 | 8/10 | ✅ 采用 | 符合理性种草定位，有成分分析 |
| 平台匹配度 | 9/10 | 🌟 表扬 | 格式、长度、标签都很适合小红书 |
| 写作质量 | 7/10 | 🔧 小改 | 结构清晰，但缺乏数据支撑 |
| 互动潜力 | 8/10 | ✅ 采用 | 实用干货，收藏价值高 |
| 风险评估 | 8/10 | ✅ 采用 | 无明显风险，建议加声明 |
| 事实核查 | 6/10 | ⚙️ 大改 | 部分声明需要来源支撑 |

### 改进建议

#### 🌟 亮点（保持）
- 使用emoji分点，视觉效果好
- 分浓度说明，体现专业性
- 个人使用体验增加可信度
- 敏感肌提醒体现负责态度

#### 🔧 优化建议
1. 添加烟酰胺功效的研究来源 - 信号值：0.0
2. 「一个月肤色提亮」可加入对比图 - 信号值：+0.5
3. 开头可以更有钩子感，如「后悔没早发现...」- 信号值：0.0

#### ⚠️ 必须修改
- 添加「个人体验，仅供参考」的声明
- 烟酰胺三大功效需要标注数据来源

---

### 事实核查详情
| 声明 | 验证状态 | 来源 |

| 烟酰胺可控油收毛孔 | ✅已验证 | 皮肤科研究证实 |
| 10%以上刺激风险增加 | ⚠️待验证 | 需补充来源 |
| 浓度分级建议 | ⚠️待验证 | 建议标注专业来源 |
```

```
- 预测准确率：66.7% (2/3维度准确)
- 最需优化的维度：事实核查
```

## 示例 3：微信公众号内容评估

### 输入

```
请评估以下内容：

【目标平台】微信公众号
【品牌定位】科技创业公司CEO个人号，分享创业思考和行业洞察
【内容草稿】

《为什么说2024是AI应用的爆发年》

2023年是AI的技术突破年，而2024年将是AI真正落地的一年。

作为一个在AI行业摸爬滚打了5年的创业者，我想分享三个观察：

一、算力成本暴降

去年同期，训练一个中等规模模型需要XX万美元，现在只需要XX万。成本下降了80%。

这意味着什么？更多的创业者可以进入这个赛道了。

二、用户认知成熟

ChatGPT让「AI」这个词从极客圈走向大众。我妈现在都会用AI帮她写祝福语了。

三、应用场景清晰

不再是「AI能做什么」，而是「AI应该先解决哪个问题」。

最后，给同样在AI领域创业的朋友一个建议：不要做平台，做垂直场景。
```
