# 学习模块文档 / Learning Module

学习模块是内容评估技能的核心增强功能，通过收集真实发布数据来持续优化评估准确性。

---

## 工作原理

```
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  内容评估预测   │ ──> │  内容发布       │ ──> │  收集真实数据   │
│  (7维度评分)    │     │  (实际上线)     │     │  (表现指标)     │
└─────────────────┘     └─────────────────┘     └─────────────────┘
                                                        │
                                                        ▼
┌─────────────────┐     ┌─────────────────┐     ┌─────────────────┐
│  更新评估模型   │ <── │  分析偏差原因   │ <── │  对比预测/实际  │
│  (权重/规则)    │     │  (校准建议)     │     │  (偏差计算)     │
└─────────────────┘     └─────────────────┘     └─────────────────┘
```

---

## 支持的学习维度（扩展版）

学习模块支持以下6个维度的量化验证：

### 1. 互动潜力 (Engagement)

**可收集的数据**：
| 指标 | 说明 | 计算方式 |
|-----|------|---------|
| 阅读/播放量 | 内容曝光 | 平台提供 |
| 点赞数 | 认可度 | 平台提供 |
| 评论数 | 讨论度 | 平台提供 |
| 转发/分享数 | 传播力 | 平台提供 |
| 收藏数 | 实用性 | 平台提供 |
| 互动率 | 综合指标 | (点赞+评论+转发+收藏)/阅读量 |

**表现评级**：
| 互动率 | 评级 | 说明 |
|-------|------|------|
| >10% | 优秀 | 爆款潜质 |
| 5-10% | 良好 | 高于平均 |
| 2-5% | 一般 | 平台平均水平 |
| <2% | 较差 | 需要改进 |

### 2. 风险评估 (Risk)

**可收集的事件**：
| 事件 | 严重程度 | 信号 | 分值调整 |
|-----|---------|------|---------|
| 被限流 | 中 | 算法降权 | -1.5 |
| 被删除 | 高 | 内容违规 | -3.0 |
| 收到平台警告 | 高 | 账号风险 | -2.5 |
| 负面舆论 | 中-高 | 品牌危机 | -2.0 |
| 用户投诉 | 中 | 内容争议 | -1.0 |

### 3. 事实核查 (Fact Check)

**可收集的反馈**：
| 反馈类型 | 说明 | 分值调整 |
|---------|------|---------|
| 用户质疑 | 评论区有人质疑事实准确性 | -1.0 |
| 需要更正 | 发布后发现错误需更正 | -2.0 |
| 专家纠正 | 被专业人士指出错误 | -2.5 |
| 事实确认 | 被权威来源证实 | +1.0 |

### 4. 平台匹配度 (Platform Fit) [新增]

**可收集的数据**：
| 指标 | 说明 | 学习价值 |
|-----|------|---------|
| 是否被推荐 | 进入平台推荐池 | 高 |
| 是否上热门 | 进入热门/热搜 | 高 |
| 曝光来源分布 | 搜索/推荐/关注/其他 | 中 |
| 推荐转化率 | 推荐曝光的互动率 | 高 |

### 5. 写作质量 (Writing Quality) [新增]

**可收集的数据**：
| 指标 | 说明 | 学习价值 |
|-----|------|---------|
| 正面评论占比 | 好评/总评论 | 高 |
| 高频正面关键词 | 评论中的正面词汇 | 中 |
| 高频负面关键词 | 评论中的负面词汇 | 中 |
| 阅读完成率 | 完整阅读的比例 | 高 |
| 二次创作数 | 被引用或模仿次数 | 中 |

### 6. 时效性 (Timeliness) [新增]

**可收集的数据**：
| 指标 | 说明 | 学习价值 |
|-----|------|---------|
| 达到峰值时间 | 发布后多久达到最高流量 | 高 |
| 流量衰减曲线 | 24h/7d/30d流量分布 | 高 |
| 长尾流量占比 | 7d后流量/总流量 | 中 |
| 二次爆发 | 是否有二次传播高峰 | 中 |

## 时序分析

收集不同时间点的数据以分析内容生命周期：

### 数据收集时间点

| 时间点 | 收集数据 | 分析目的 |
|-------|---------|---------|
| 1h | 初始反应 | 判断标题/封面吸引力 |
| 24h | 初始表现 | 判断是否进入推荐池 |
| 7d | 稳定表现 | 评估实际传播效果 |
| 30d | 长尾表现 | 分析内容长期价值 |

### 生命周期类型

| 类型 | 特征 | 典型内容 |
|-----|------|---------|
| 爆发型 | 24h达到峰值，7d后衰减90% | 热点追踪、新闻 |
| 平稳型 | 48-72h达到峰值，缓慢衰减 | 深度分析、教程 |
| 长尾型 | 持续稳定流量，无明显峰值 | 常青内容、工具类 |
| 二次爆发 | 有多个流量高峰 | 被大V转发、二次创作 |

## 数据存储

学习数据存储在 `templates/learning-history.md` 文件中，格式化为可追溯的历史记录。

### 数据保留策略

| 数据类型 | 保留时间 | 存储方式 |
|---------|---------|---------|
| 详细记录 | 最近100条 | 完整保存 |
| 历史数据 | 永久 | 归档为统计摘要 |
| A/B测试 | 最近50条 | 完整保存 |

### 数据筛选

支持按以下维度筛选历史数据：
- 平台：小红书/公众号/抖音/知乎/B站/微博
- 时间：最近7天/30天/90天/全部
- 内容类型：新闻资讯/种草推荐/观点评论/教程干货
- 表现：优秀/良好/一般/较差

## 最佳实践

### 数据收集建议

1. **及时反馈**：
   - 发布后24h收集初始数据
   - 发布后7d收集稳定数据
   - 发布后30d收集长尾数据（可选）

2. **完整记录**：
   - 尽量提供所有可用指标
   - 标注缺失数据原因

3. **标注异常**：
   - 热点加成需标注
   - 付费推广需标注
   - 异常事件需说明

4. **定期回顾**：
   - 每周查看最近数据趋势
   - 每月查看累计统计报告
   - 每季度评估模型准确性

### A/B测试建议

1. **单一变量**：每次只测试一个变量
2. **足够样本**：确保样本量达到统计显著性
3. **同时测试**：A/B版本同时发布，避免时间偏差
4. **记录结论**：将测试结论归档，避免重复测试

### 置信度提升

| 条件 | 置信度 |
|------|-------|
| 该品牌/平台有≥20条历史数据 | 高 (90%) |
| 该品牌/平台有5-19条历史数据 | 中 (70%) |
| 该品牌/平台有<5条历史数据 | 低 (50%) |

**提升置信度的方法**：
- 持续收集反馈数据
- 保持数据质量（完整、准确）
- 覆盖多种内容类型
