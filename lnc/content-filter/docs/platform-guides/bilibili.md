# B站平台指南 / Bilibili Guide

## 平台概述

Bilibili（B站）是中国最大的年轻人文化社区和视频平台，以弹幕文化、二次元内容起家，现已发展为综合性视频社区。

### 用户画像

| 维度 | 特征 |
|-----|------|
| 年龄 | Z世代为主（18-30岁占80%） |
| 性别 | 男女比例接近均衡 |
| 学历 | 大学生和年轻白领为主 |
| 地域 | 一二线城市为主 |
| 特点 | 追求有趣、真诚、有深度的内容 |
| 社区感 | 强烈的社区归属感和圈层文化 |

### 2026年重大变化

| 变化 | 影响 |
|-----|------|
| 分享权重暴涨 | 分享成为第一权重指标，超过点赞和投币 |
| 48小时黄金窗口 | 发布后48小时内的表现决定视频命运 |
| 20%探索流量 | 算法保留20%流量给新创作者和探索性内容 |
| 完播率细分 | 区分"主动完播"和"被动播放"，主动完播权重更高 |
| AI内容标识 | AI生成内容需要标注，影响推荐权重 |

## 内容规范

### 最佳内容格式

```
【时长】3-15分钟（黄金时长），知识类可延长至30分钟
【比例】16:9 横屏为主，部分内容支持竖屏
【封面】高清、有设计感、能体现内容亮点
【标题】直接、有趣、避免标题党
【简介】包含关键信息和互动引导
【标签】5-10个相关标签
【分区】选择最匹配的内容分区
```

### B站特有的内容要素

**弹幕设计**：
- 预设弹幕引导点（"弹幕护体"、"前方高能"）
- 在精彩处设计弹幕互动点
- 鼓励观众发弹幕参与

**三连引导**：
- 点赞（表示认可）
- 投币（表示非常认可，需要B币）
- 收藏（表示有价值，想再看）

### 内容结构

```markdown
B站视频结构
├── 0-30秒：开头
│   ├── 亮点/结果预览
│   ├── 主题引入
│   └── 建立期待
│
├── 30秒-主体：核心内容
│   ├── 分段清晰
│   ├── 节奏有变化
│   ├── 设置弹幕点
│   └── 保持信息密度
│
├── 结尾前1分钟：总结
│   ├── 核心要点回顾
│   └── 下期预告（如有）
│
└── 最后30秒：互动引导
    ├── 三连请求
    ├── 关注引导
    └── 评论区话题
```

## 算法偏好

### 流量分配机制（2026年更新）

```
发布 → 初始推荐（关注者+小范围推荐+20%探索流量）
     ↓ 48小时黄金窗口
     ↓ 完播率/分享率达标
     扩大推荐（分区推荐）
     ↓ 分享持续增长
     首页推荐
     ↓ 成为热门
     全站推荐/热门榜单
```

**2026年核心变化**：
- 48小时内的表现决定视频命运
- 分享成为晋级的核心指标
- 20%流量保留给新人和探索内容

### 关键指标（2026年权重更新）

| 指标 | 权重 | 说明 | 优化方向 |
|-----|------|------|---------|
| 分享率 | 最高 | 站外/站内分享（2026年升为第一） | 创造分享价值 |
| 完播率（主动） | 极高 | 用户主动看完比例 | 控制时长、内容紧凑 |
| 三连率 | 高 | 点赞+投币+收藏 | 优质内容+引导 |
| 弹幕数 | 高 | 弹幕互动 | 设计弹幕点 |
| 评论数 | 高 | 评论区互动 | 引导讨论话题 |
| 关注转化 | 中高 | 看后关注比例 | 人设建设、系列内容 |

### 完播率优化

| 视频时长 | 优化策略 |
|---------|---------|
| <5分钟 | 信息密集、节奏快 |
| 5-10分钟 | 分段清晰、有节奏变化 |
| 10-20分钟 | 多设置记忆点和高潮 |
| >20分钟 | 分章节、有目录 |

### 发布时间建议

| 时段 | 适合内容 | 竞争程度 |
|-----|---------|---------|
| 10:00-12:00 | 知识、教程类 | 中 |
| 14:00-16:00 | 游戏、娱乐类 | 中 |
| 18:00-20:00 | 生活、美食类 | 高 |
| 20:00-23:00 | 番剧、深度类 | 最高 |
| 周末全天 | 娱乐、影视类 | 高 |

## 合规红线

### 绝对禁止

- 政治敏感内容
- 低俗/软色情内容
- 未授权的版权内容（影视、音乐等）
- 引战/地域黑/人身攻击
- 虚假宣传/欺诈
- 血腥暴力内容

### 需要注意

- 影视剪辑需注意版权
- 游戏内容需符合游戏分级
- 商业推广需标注"商单"
- 敏感话题需谨慎处理
- 避免过度标题党

### 常见问题

1. **审核不通过**：
   - 检查是否有版权问题
   - 检查是否有敏感画面/言论
   - 检查标题/封面是否违规

2. **流量异常**：
   - 内容质量问题
   - 标题封面不吸引
   - 发布时间不佳

## 内容类型策略

### 主要内容分区

| 分区 | 特点 | 用户偏好 |
|-----|------|---------|
| 知识区 | 教程、科普、学习 | 干货、系统性 |
| 生活区 | vlog、日常、美食 | 真实、有趣 |
| 游戏区 | 游戏实况、攻略 | 技术、娱乐性 |
| 影视区 | 影评、剪辑、混剪 | 创意、情怀 |
| 科技区 | 数码评测、技术 | 专业、客观 |
| 动画区 | 二次元、MAD | 创意、情怀 |

### 各类型评估重点

**知识类**：
- 信息是否准确
- 讲解是否清晰
- 是否有系统性
- 是否有实用价值

**娱乐类**：
- 是否有趣/有梗
- 节奏是否流畅
- 是否有记忆点
- 弹幕互动潜力

**技术类**：
- 技术是否专业
- 演示是否清晰
- 是否有干货
- 可复制性

## B站特色文化

### 弹幕文化

**常见弹幕梗**：
- "前方高能" - 精彩预警
- "弹幕护体" - 恐怖场景
- "开始了" - 关键内容开始
- "来了来了" - 期待的内容出现
- "爷青回" - 怀旧内容

**弹幕设计技巧**：
- 在关键时刻预留弹幕空间
- 用字幕引导弹幕话题
- 设计可以刷的统一弹幕

### 社区文化

**B站用户偏好**：
- 真诚 > 精致
- 有趣 > 有用
- 深度 > 快餐
- 用心 > 流水线

**忌讳**：
- 过度商业化
- 敷衍式内容
- 标题党严重
- 蹭热度无底线

## 评估特别提示

在B站内容评估时，额外关注：

### 必须检查项

1. **内容质量**：是否用心制作、有价值
2. **社区适配**：是否符合B站调性
3. **完播率预测**：节奏是否能支撑完播
4. **三连潜力**：是否值得投币收藏
5. **弹幕互动**：是否有弹幕互动点

### 加分项

- 有独特的人设/风格
- 内容有系列感
- 有B站特有的梗和互动
- 制作精良（剪辑、字幕、特效）
- 评论区互动好

### 减分项

- 明显的流水线内容
- 过度商业化/广告感
- 与B站调性不符
- 内容过长但密度低
- 标题党严重

## 长期运营建议

### 账号定位

1. **找到细分领域**：避免大而全，专注垂直内容
2. **建立人设**：有辨识度的形象和风格
3. **系列化内容**：打造系列IP，培养观众期待
4. **社区互动**：认真回复评论，建立粉丝关系

### UP主成长路径

```
新人期（0-1万粉）
├── 找准定位
├── 保证更新频率
└── 学习基础剪辑

成长期（1-10万粉）
├── 优化内容质量
├── 建立人设特色
└── 适度商业化

成熟期（10万+粉）
├── 内容IP化
├── 多元变现
└── 团队化运营
```
