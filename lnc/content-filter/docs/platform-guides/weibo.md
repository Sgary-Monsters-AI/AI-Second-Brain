# 微博平台指南 / Weibo Guide

## 平台概述

微博是中国最大的社交媒体平台之一，以实时热点、名人动态和公共讨论著称。截至2025年6月，月活用户5.88亿，日活用户2.61亿。2026年，平台通过"热点域"产品和算法推荐优化，强化媒体内容权重，推荐流日活同比增长30%。

### 用户画像

| 维度 | 特征 |
|-----|------|
| 年龄 | 18-40岁为主（30岁以下占70.7%） |
| 性别 | 女性略多（55%） |
| 地域 | 全国覆盖，一二线城市更活跃 |
| 特点 | 追热点、关注明星、参与公共讨论 |
| 使用场景 | 碎片化浏览、热点追踪、社交互动 |
| 日均行为 | 发博1.05亿条，评论6300万条，点赞1.97亿次 |

### 2026年重大变化

| 变化 | 影响 |
|-----|------|
| 媒体内容权重提升 | 热搜前十媒体主持内容从41%提升到65% |
| 推荐流增长 | 首页推荐流日活同比增长30%，兴趣内容阅读量提升24% |
| 热点域产品 | 在热搜之外打造"发现页热点流" |
| 账号信用分体系 | 热评需650分，热门转发需690分 |
| 即时反馈内容 | 基于互动的即时反馈内容带来17%流量增长 |

## 内容规范

### 内容形式

| 形式 | 长度限制 | 适用场景 |
|-----|---------|---------|
| 短微博 | 140字内 | 观点表达、热点评论 |
| 长微博 | 无限制 | 深度分析、长文 |
| 图文 | 最多9图 | 产品展示、教程 |
| 视频 | 15分钟内 | 视频内容 |
| 头条文章 | 无限制 | 深度长文 |

### 短微博写作技巧

```markdown
高互动短微博结构
├── 开头（1-2句）：观点/悬念/痛点
├── 主体（3-5句）：论述/展开/证据
└── 结尾（1句）：总结/互动引导
```

**有效的开头方式**：
| 方式 | 示例 |
|-----|------|
| 热点关联 | "看到XX新闻，想说几句..." |
| 争议观点 | "可能很多人不同意，但..." |
| 数字冲击 | "统计了100个案例，发现..." |
| 情绪表达 | "真的被气到了/感动到了..." |
| 问题引导 | "有没有人和我一样觉得..." |

### 长微博/头条文章

- 使用分段和小标题
- 重点内容加粗
- 适当配图
- 结尾要有互动引导

## 算法偏好

### 流量分配机制

```
发布 → 粉丝可见（部分）
     ↓ 互动率达标
     扩大推荐范围
     ↓ 持续互动
     进入热门流
     ↓ 超高互动
     上热搜/话题榜
```

### 关键指标

| 指标 | 权重 | 说明 |
|-----|------|------|
| 转发数 | 最高 | 传播核心指标 |
| 评论数 | 高 | 讨论热度 |
| 点赞数 | 中 | 认可度 |
| 阅读量 | 中 | 曝光基础 |
| 话题热度 | 高 | 与热点关联度 |

### 热点追踪策略

**热点生命周期**：
| 阶段 | 时间 | 策略 |
|-----|------|------|
| 爆发期 | 0-2h | 快速发布，抢占先机 |
| 上升期 | 2-12h | 深度解读，差异化观点 |
| 顶峰期 | 12-24h | 总结梳理，提供价值 |
| 衰退期 | 24h+ | 避免追热点，已晚 |

### 发布时间建议

| 时段 | 特点 | 建议内容 |
|-----|------|---------|
| 7:00-9:00 | 早间浏览高峰 | 早安类、资讯类 |
| 12:00-14:00 | 午休高峰 | 轻松、娱乐类 |
| 18:00-20:00 | 下班高峰 | 热点评论、生活分享 |
| 21:00-24:00 | 深夜活跃 | 情感、深度内容 |

## 合规红线

### 绝对禁止

- 政治敏感内容
- 造谣传谣
- 人身攻击/网暴
- 色情低俗
- 违法信息
- 恶意营销

### 需要注意

- 转发未经证实的信息需谨慎
- 涉及公众人物需有依据
- 商业推广需标注
- 敏感话题需把控尺度

### 常见违规

1. **账号被限流**：
   - 频繁发布营销内容
   - 使用违规关键词
   - 被大量举报

2. **内容被删除**：
   - 涉及敏感话题
   - 传播不实信息
   - 侵犯他人权益

## 评估特别提示

在微博内容评估时，额外关注：

### 必须检查项

1. **时效性**：是否与当前热点相关
2. **观点明确**：是否有清晰的立场
3. **情绪适度**：表达是否得当
4. **话题选择**：话题是否匹配
5. **互动引导**：是否有转评引导

### 加分项

- 抓住热点上升期
- 观点独特有见地
- 有数据/证据支撑
- 文案有传播性
- 图片/视频质量高

### 减分项

- 热点已过期
- 立场模糊
- 纯搬运无观点
- 话题不匹配
- 过度营销感
