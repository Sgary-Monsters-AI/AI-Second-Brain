# 微信公众号平台指南 / WeChat Official Account Guide

## 平台概述

微信公众号是中国最重要的内容订阅平台，以私域流量和深度内容著称。2026年，算法推荐成为流量分配的核心引擎，从"粉丝订阅"向"社交口碑+算法推荐"双驱动转型。

### 用户画像

| 维度 | 特征 |
|-----|------|
| 年龄 | 全年龄段覆盖 |
| 场景 | 通勤、碎片时间、睡前 |
| 习惯 | 订阅式阅读，信任度高 |
| 特点 | 忠诚度高，付费意愿强 |

### 2026年重大变化

| 变化 | 影响 |
|-----|------|
| 算法推荐成为核心 | 流量分配从"关注"向"社交口碑+算法价值判断"转移 |
| 三大隐性指标 | 完读率、互动率、社交分享成为关键考核维度 |
| 推荐周期延长 | 优质文章可获得连续7天甚至更长的推荐 |
| AI文章识别 | 简单复制粘贴的AI文章会被精准识别并限制推荐 |
| 新人友好 | 有了算法推荐，新作者不再受歧视，好内容即可获得流量 |

## 内容规范

### 最佳内容格式

```
【标题】18字以内，直击痛点或好奇心
【封面】清晰、有品牌调性
【正文】1500-3000字，排版精美
【引导】文末关注、点赞、在看引导
```

### 标题技巧

**有效公式**：
- 悬念型：「为什么90%的人都做错了这件事」
- 数字型：「成功人士的5个习惯」
- 对比型：「普通人和高手的区别」
- 痛点型：「你的努力，为什么总是没结果」
- 权威型：「XXX都在用的方法」

**2026年注意事项**：
- 标题质量决定打开率（占40%权重）
- 避免标题党，与内容不符会被降权
- AI生成的模板化标题会被识别

### 文章结构

**爆款结构**：
```
开头（200字内）
├── Hook：故事/问题/金句
├── 引入主题
│
主体
├── 分论点1 + 案例/数据
├── 分论点2 + 案例/数据
├── 分论点3 + 案例/数据
│
结尾
├── 总结升华
├── 金句收尾
├── 引导互动（重点：引导深度评论和分享）
```

### 排版规范

- 段落：3-4行一段
- 行距：1.75-2倍
- 字号：15-16px
- 字间距：1-1.5px
- 配图：每300-500字配一图

## 算法/分发特点（2026年更新）

### 2026年三大核心指标

| 指标 | 权重 | 说明 |
|-----|------|------|
| 打开率（CTR） | 40% | 标题和封面吸引力 |
| 互动率 | 30% | 赞/在看/收藏，优质评论是黄金 |
| 分享率 | 20% | 社交传播，圈层内被分享=优质资产 |
| 完读率 | 10% | 读者是否真的"读完" |

### 流量来源（2026年更新）

| 来源 | 占比 | 说明 |
|-----|------|------|
| 算法推荐 | 30-40% | 2026年大幅提升 |
| 订阅号消息 | 30-40% | 粉丝直接阅读 |
| 朋友圈 | 15-25% | 粉丝分享 |
| 看一看 | 10-15% | 社交推荐 |
| 搜一搜 | 5-10% | 搜索流量 |

### 推荐机制特点

1. **推荐周期延长**：一篇文章的推荐周期不是一天，优质文章可能连续7天都在推荐
2. **更新频率影响**：过高的更新频率反而会冲掉上一篇文章的推荐
3. **新人机会**：新作者不受歧视，好内容可以直接获得几万甚至10万+流量
4. **AI内容识别**：简单复制粘贴的AI文章会被识别并限制推荐

### 发布时间建议

| 时段 | 适合类型 | 推荐策略 |
|-----|---------|---------|
| 6:30-8:00 | 新闻、资讯、早报 | 抢占早间流量 |
| 11:30-13:00 | 轻松、职场、生活 | 午餐时段 |
| 17:30-19:00 | 干货、深度 | 下班通勤 |
| 21:00-22:30 | 情感、故事、思考 | 睡前阅读 |

**2026年建议**：控制发布频率，质量优先于数量，避免高频发布冲掉推荐。

## 合规要求

### 内容红线

- 时政敏感内容
- 未经授权的新闻采编
- 虚假信息
- 侵权内容
- 低俗内容

### 标题规范

- 不得使用「震惊体」
- 不得标题与内容不符
- 不得使用诱导性标题

### 原创保护

- 开通原创标签
- 注意转载授权
- 避免洗稿
- AI生成内容需要人工优化和改写

## 内容评估特别提示

在公众号内容评估时，额外关注：

### 必须检查项（2026年权重）

1. **标题质量**（40%）：决定打开率，需反复打磨
2. **开头吸引力**：前100字决定是否继续阅读
3. **完读率设计**：内容节奏是否支撑读者读完
4. **金句密度**：是否有可截图分享的金句
5. **互动引导**：是否有效引导评论和分享
6. **排版美观**：阅读体验是否舒适

### 加分项

- 内容有深度思考，非AI模板化
- 有可分享的金句或观点
- 引导深度评论而非简单点赞
- 系列化内容，培养读者期待
- 与热点结合但有独特视角

### 减分项

- AI生成的模板化内容
- 标题党，与内容不符
- 过度追求更新频率
- 缺乏互动引导
- 排版混乱

## 2026年运营建议

### 内容策略

1. **质量优先**：优质、原创、能激发深度互动的内容
2. **控制频率**：避免日更稀释单篇推荐价值
3. **深度互动**：引导评论而非简单点赞/在看
4. **社交传播**：创造值得分享的金句和观点

### 增长策略

1. **算法友好**：关注完读率、互动率、分享率
2. **新人机会**：新账号好内容同样能获得流量
3. **长尾价值**：优质文章可获得7天+的推荐周期
4. **避免AI依赖**：简单AI生成内容会被识别限制
