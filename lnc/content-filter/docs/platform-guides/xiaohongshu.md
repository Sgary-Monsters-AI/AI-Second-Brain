小红书是中国领先的生活方式分享社区，以"种草"文化闻名，月活用户超过3亿。2026年算法从"内容推荐"转向"搜索+兴趣+转化"三位一体的智能分发体系。

### 2026年重大变化

## 内容规范

### 最佳内容格式

```
【标题】包含核心词+长尾词+场景词，吸引眼球，可适当使用emoji
【封面】高质量图片，清晰美观，第一张最重要
【正文】300-800字，分段清晰，使用emoji分隔
【标签】5-10个相关标签，包含热门和长尾
```

### 标题技巧（2026年权重提升40%）

**关键词布局策略**：
```
标题 = 核心词 + 长尾词 + 场景词/情感词

示例：
核心词：护肤
长尾词：干皮、秋冬、平价
场景词：学生党

完整标题：「干皮秋冬救星！学生党平价护肤清单」
```

**有效公式**：
- 数字 + 结果：「3步搞定完美底妆」
- 痛点 + 解决方案：「毛孔粗大？这招救了我」
- 身份 + 经验：「作为干皮5年的我...」
- 对比 + 反转：「从月光族到存下10万」
- 测评 + 结论：「亲测30款粉底，这5款最好用」

**2026年标题红线**：
- 关键词堆砌会被判定为广告导致降权
- 标题党（与内容不符）会被限流
- 过度夸张会触发人工审核

### 正文结构

```markdown
Hook（开头吸引）
├── 痛点共鸣 / 结果预告 / 悬念设置
│
主体内容
├── 分点陈述（使用emoji作为bullet）
├── 个人体验（增加可信度）- 2026年真实体验权重大增
├── 干货信息（收藏价值）
├── 具体细节（可验证性）- 2026年新增考核维度
│
结尾
├── 总结 / 互动引导 / 行动号召
```

## 算法偏好（2026年更新）

### CES算法（社区互动分）- 2026年升级版

**计算公式**：
```
CES = 点赞×1 + 收藏×1 + 评论×4 + 转发×4 + 关注×8
```

**2026年新增考核维度**：
| 维度 | 权重 | 说明 |
|-----|------|------|
| 点击率 | 高 | 封面和标题吸引力 |
| 完播率 | 高 | >40%才能触发二级推荐 |
| 互动值 | 高 | 长评论、深度阅读、截屏等高质量互动权重更高 |
| 真实性 | 中高 | 可验证、有细节、非虚构 |
| 稀缺性 | 中高 | 非同质化、有独特价值 |

### 流量分配机制（2026年更新）

```
发布 → AI审核（<5秒）→ 打标签匹配
     ↓
初始流量池(200-500曝光)
     ↓ 完播率>40% + 互动率达标
中级流量池(1000-5000曝光)

高级流量池(10000+曝光)
     ↓ 进入搜索推荐
搜索+推荐双通道放大
```

## 合规红线

### 绝对禁止

- 医疗功效宣称（治疗、治愈等）
- 金融投资建议
- 违规引流（私信加微信等）
- 抄袭搬运
- 虚假宣传
- 未标注AI生成内容（2026年新规）

### 需要注意

- 品牌合作需标注「广告」「合作」
- AI生成内容必须标注，否则流量降低40%+
- 敏感话题谨慎处理
- 避免过度修图
- 不要使用非授权图片
- 文案重复率>70%会触发限流

### 常见限流原因

1. **内容原因**：
   - 笔记含敏感词
   - AI生成内容未标注
   - 同质化内容（重复率>70%）
   - 广告嫌疑过重

2. **账号原因**：
   - 短时间大量发布
   - 互动异常（刷数据）
   - 被举报
   - 信用分低于标准

3. **技术原因**：
   - 关键词堆砌
   - 标题与内容不符
   - 使用违规关键词

## 内容类型策略

### 2026年高流量内容特征

| 特征 | 说明 |
|-----|------|
| 真实性 | 可验证、有细节、非虚构 |
| 稀缺性 | 非同质化、有独特价值、填补信息空白 |
| 搜索友好 | 包含高意图关键词 |
| 互动设计 | 有引导评论、收藏的设计 |

### 内容类型评估重点

**种草类**：
- 是否有真实使用体验（2026年核心）
- 是否提供具体细节（可验证性）
- 是否有对比和结论
- 关键词是否覆盖目标搜索词

**攻略类**：
- 信息是否有稀缺价值
- 是否提供可操作的步骤
- 是否覆盖用户搜索的长尾词
- 是否值得收藏

**测评类**：
- 是否有真实测试过程
- 是否有具体数据/对比
- 结论是否明确
- 是否解答用户搜索的问题

## 评估特别提示

在小红书内容评估时，额外关注：

### 必须检查项

1. **搜索优化**：标题是否包含核心词+长尾词
2. **封面吸引力**：第一张图是否能驱动点击
3. **真实性**：内容是否有可验证的细节和个人体验
4. **干货密度**：是否有足够的收藏价值
5. **互动设计**：结尾是否有互动引导（长评论价值更高）
6. **AI标注**：AI生成内容是否已标注

### 加分项

- 内容有稀缺价值，非同质化
- 有数据支撑或对比测评
- 关键词自然融入，覆盖搜索意图
- 真实体验+具体细节
- 互动设计引导深度评论

### 减分项

- 内容同质化，与已有笔记重复
- 关键词堆砌或与内容不符
- 缺乏真实体验，过于模板化
- AI生成内容未标注
- 纯搬运无个人观点
