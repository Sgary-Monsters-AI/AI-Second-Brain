# 抖音平台指南 / Douyin Guide

## 平台概述

抖音是中国最大的短视频平台，以算法推荐和娱乐内容著称，日活用户超过7亿。2026年算法引入"用户不后悔时长"概念，推流周期从24小时延长至7天。

### 用户画像

| 维度 | 特征 |
|-----|------|
| 年龄 | 全年龄段，18-35岁为主力 |
| 性别 | 男女比例接近 1:1 |
| 地域 | 全国覆盖，下沉市场渗透率高 |
| 消费力 | 覆盖各层级，直播电商活跃 |
| 使用时长 | 日均90分钟以上 |
| 兴趣 | 娱乐、生活、知识、电商 |

### 2026年重大变化

| 变化 | 影响 |
|-----|------|
| 用户不后悔时长 | 用户看完后无互动/点"不感兴趣"=无效供给，流量被锁死 |
| 推流周期延长 | 从24小时延长至最长7天，发布当天数据不佳不代表失败 |
| 高成本互动权重暴涨 | 长评论、主动分享的权重大幅提升 |
| 三级火箭模型 | 创作者分级(S/A/B/C)，S级账号获双倍流量加持 |
| 去超头化 | 减少头部主播流量倾斜，扶持中小商家和品牌自播 |

## 内容规范

### 最佳内容格式

```
【时长】15-60秒（黄金时长），知识类可延长至3分钟
【比例】9:16 竖屏
【封面】高清、有吸引力的首帧或自定义封面
【字幕】必须添加，提升完播率
【BGM】选择热门音乐或原创音乐
【标签】3-5个相关话题标签
```

### 前3秒法则

**抖音的前3秒决定生死**，用户平均划走时间不到3秒。2026年算法中，前3秒留存率权重占比高达40%。

**有效的开头技巧**：
| 技巧 | 示例 | 效果 |
|-----|------|------|
| 悬念开头 | "你绝对想不到..." | 引发好奇 |
| 结果前置 | "用这个方法，我瘦了20斤" | 展示价值 |
| 痛点共鸣 | "是不是你也有这个烦恼？" | 建立连接 |
| 争议观点 | "大多数人都错了！" | 制造冲突 |
| 数字冲击 | "99%的人不知道..." | 引发兴趣 |

**避免的开头**：
- 自我介绍过长
- 无关紧要的铺垫
- 画质模糊/声音不清
- 没有字幕

### 内容结构

```markdown
黄金结构（60秒内）
├── 0-3秒：钩子（Hook）- 抓住注意力（权重40%）
├── 3-10秒：痛点/问题 - 建立共鸣
├── 10-45秒：核心内容 - 提供价值
├── 45-55秒：总结/升华 - 强化记忆
└── 55-60秒：互动引导 - 引导长评论和分享
```

## 算法偏好（2026年更新）

### 三级火箭模型（2026年核心机制）

```
第一级：创作者分级体系
├── S级账号：双倍流量加持
├── A级账号：正常流量
├── B级账号：流量受限
└── C级账号：低流量

第二级：流量池晋级机制
├── 冷启动池：500-1000曝光
├── 完播率≥40% → 进入下一级
├── 前3秒留存率权重40%
└── 层层晋级至推荐池

第三级：动态校准系统
├── 推流周期延长至7天
└── 持续评估内容价值
```

### "用户不后悔时长"概念（2026年新核心指标）

2026年算法的核心判断标准：**用户看完后是否后悔**

| 用户行为 | 算法判定 |
|---------|---------|
| 看完+点赞/评论/分享 | 有效供给，继续推荐 |
| 看完但无任何互动 | 可疑，观察 |
| 看完+点"不感兴趣" | 无效供给，锁死流量 |
| 中途划走 | 降低完播率，减少推荐 |

### 互动权重变化（2026年更新）

| 互动类型 | 2025年权重 | 2026年权重 | 变化 |
|---------|-----------|-----------|------|
| 长评论（打字） | 中高 | 最高 | ↑↑ |
| 主动分享 | 中高 | 极高 | ↑↑ |
| 收藏 | 中 | 中高 | ↑ |
| 普通评论 | 中 | 中 | - |
| 点赞 | 高 | 中 | ↓ |
| 完播 | 最高 | 高 | ↓ |

**核心变化**：长评论和分享被视为"高成本互动"——用户愿意打字说明深度思考，愿意分享说明用自身信用背书。

### 流量分配机制（2026年更新）

```
发布 → 冷启动池(500-1000播放)
     ↓ 完播率≥40% + 前3秒留存
     中级流量池(5000-10000播放)
     ↓ 高成本互动（长评论/分享）达标
     高级流量池(10000-100000播放)
     ↓ 7天内持续优秀表现
     推荐池(100万+播放)
```

**注意**：推流周期延长至7天，发布当天数据不佳不代表作品失败，平台需要更多时间评估内容价值。

### 关键指标权重（2026年）

| 指标 | 权重 | 说明 | 优化方向 |
|-----|------|------|---------|
| 前3秒留存率 | 最高(40%) | 决定是否进入流量池 | 开头直接抓人 |
| 完播率 | 高 | ≥40%是晋级门槛 | 控制时长、内容紧凑 |
| 长评论数 | 高 | 高成本互动 | 引导深度讨论 |
| 分享率 | 高 | 用户用信用背书 | 提供分享价值 |
| 关注转化 | 中高 | 账号价值 | 人设建设、系列内容 |
| 点赞数 | 中 | 基础认可（权重下降） | 引导互动 |

### 完播率优化技巧

| 技巧 | 说明 |
|-----|------|
| 控制时长 | 新号建议15-30秒，成熟账号可延长 |
| 节奏紧凑 | 每3-5秒一个信息点 |
| 视觉变化 | 多角度、多场景切换 |
| 字幕引导 | 关键信息用字幕强调 |
| 悬念保持 | 结尾有反转或彩蛋 |

### 发布时间建议

| 时段 | 适合内容 | 竞争程度 |
|-----|---------|---------|
| 7:00-9:00 | 知识干货、励志内容 | 中 |
| 12:00-14:00 | 轻松娱乐、美食 | 高 |
| 17:00-19:00 | 下班解压、生活分享 | 高 |
| 21:00-23:00 | 情感、深度内容 | 最高 |
| 周末全天 | 娱乐、旅行、亲子 | 高 |

## 审核机制（2026年更新）

### 三重审核机制

```
第一重：机器审核（初审）
├── 所有内容发布后经100+风险模型筛查
├── 检测违规词、侵权、硬广等
└── 风险内容转入人工审核

第二重：流量触发复审
├── 播放量突破10万时触发
└── 二次机器审核

第三重：人工复审
├── 播放量达到50万时触发
└── 人工深度审核
```

### 审核注意事项

- 高播放量内容会触发更严格审核
- 7天推流周期内可能多次被审核
- 边缘内容可能前期放量后期被限

## 合规红线

### 绝对禁止

- **政治敏感**：涉及政治人物、国家政策的负面内容
- **虚假宣传**：虚假功效、夸大效果
- **低俗内容**：软色情、低俗擦边
- **危险行为**：危险挑战、不良示范
- **版权侵权**：未授权使用他人作品
- **违规引流**：引导添加微信等私域

### 需要注意

- 医疗健康类需要资质
- 金融理财类需要谨慎
- 美妆护肤避免功效宣称
- 食品类避免绝对化用语
- 直播带货需遵守电商规范

### 常见限流原因

1. **内容原因**：
   - 含敏感词或违规画面
   - 搬运或重复内容
   - 广告嫌疑过重
   - 用户"不感兴趣"反馈多

2. **账号原因**：
   - 频繁发布（建议每日1-3条）
   - 互动异常（刷数据）
   - 被用户举报
   - 账号等级低（C级）

3. **技术原因**：
   - 画质过低
   - 有明显水印
   - 横屏内容

## 内容类型策略

### 高流量内容类型

| 类型 | 特点 | 流量潜力 | 变现潜力 |
|-----|------|---------|---------|
| 剧情/段子 | 娱乐性强、易传播 | 极高 | 中 |
| 知识干货 | 实用价值、收藏高 | 高 | 高 |
| 好物推荐 | 种草属性、带货强 | 中高 | 极高 |
| 生活记录 | 真实感、共鸣强 | 中 | 中 |
| 技能教学 | 可复制、实操性强 | 高 | 高 |
| 颜值类 | 视觉吸引、互动高 | 高 | 中 |

### 2026年内容趋势

| 趋势 | 说明 |
|-----|------|
| 垂直细分 | 专注细分赛道的创作者，平均播放量高出41% |
| 长期价值 | 收藏率和复访率成为流量核心 |
| 知识服务 | 从快餐式内容转向有长期价值的知识服务类内容 |
| 品牌自播 | 店播GMV占比达30%，超越达人直播 |

### 各类型评估重点

**剧情类**：
- 前3秒是否有悬念
- 剧情是否有反转
- 演技是否自然
- 节奏是否紧凑

**知识类**：
- 信息密度是否足够
- 是否易于理解
- 是否有实操价值
- 专业性是否可信

**带货类**：
- 产品展示是否清晰
- 卖点是否突出
- 是否有使用场景
- 价格是否有吸引力

## 评估特别提示

在抖音内容评估时，额外关注：

### 必须检查项

1. **前3秒吸引力**：是否能在前3秒抓住观众（权重40%）
2. **完播率预测**：内容节奏是否能支撑40%+完播率
3. **高成本互动设计**：是否有引导长评论/分享的设计
4. **BGM选择**：是否使用热门或合适的音乐
5. **字幕质量**：是否有清晰的字幕

### 加分项

- 使用热门话题/挑战
- 有明显的人设特色
- 内容有系列感
- 评论区有互动策略（引导长评论）
- 提供分享价值

### 减分项

- 开头平淡无钩子
- 时长过长（超过60秒但无必要）
- 没有字幕
- 画质不清晰
- 水印明显
- 无互动引导设计
