# 评估维度详解 / Evaluation Dimensions

本文档详细说明7个评估维度的理论基础、评分标准和应用场景。

---

## 1. 品牌一致性 (Brand Consistency) - 权重 10%

### 理论基础

品牌一致性基于品牌资产理论（Brand Equity Theory），强调持续一致的品牌表达能够：
- 建立品牌认知和记忆
- 增强用户信任
- 形成差异化竞争优势

### 品牌配置系统

为了更精准地评估品牌一致性，系统支持**品牌配置文件**功能：

**配置文件位置**：`brands/` 目录

**预置配置**：
| 配置文件 | 适用场景 |
|---------|---------|
| `skincare-blogger.md` | 护肤/美妆博主 |
| `tech-ceo.md` | 科技创业者/CEO |
| `lifestyle-kol.md` | 生活方式KOL |
| `mom-reading-club.md` | 妈妈阅读俱乐部 |

**品牌信息来源优先级**：
1. 品牌配置文件（最完整）
2. 即时品牌定位描述
3. 无品牌信息（跳过此维度）

### 评估要素

| 要素 | 说明 | 权重 |
|-----|------|------|
| 语言风格 | 文字调性是否与品牌定位一致 | 30% |
| 价值观 | 传达的理念是否符合品牌价值观 | 25% |
| 视觉调性 | 图文风格是否统一（如适用） | 20% |
| 人设一致 | 个人IP是否保持人设一致性 | 25% |

### 配置文件评估细分

使用品牌配置文件时，评估会更细致地参考以下维度：

| 配置部分 | 评估重点 | 占比 |
|---------|---------|------|
| 品牌基础信息 | 是否符合品牌定位和目标受众 | 20% |
| 品牌调性 | 语言风格、情感基调、标志表达是否一致 | 35% |
| 内容边界 | 是否在允许范围内，有无触碰禁区 | 25% |
| 平台策略 | 是否符合该平台的差异化策略 | 10% |
| 一致性检查点 | 是否通过必须符合项，有无触碰红线 | 10% |

### 评分标准（量化版）

| 分数区间 | 标准 | 量化检查点 |
|---------|------|-----------|
| 9-10 | 完美契合，强化品牌认知 | 符合所有必须项 + 80%建议项 |
| 7-8 | 基本符合，无明显偏离 | 符合所有必须项 + 50%建议项 |
| 5-6 | 部分偏离，需要调整 | 符合80%必须项 |
| 3-4 | 明显偏离品牌定位 | 符合50%必须项 |
| 0-2 | 与品牌形象严重冲突 | 触碰红线或<50%必须项 |

## 2. 平台匹配度 (Platform Fit) - 权重 15%

### 理论基础

基于媒介生态理论（Media Ecology），不同平台形成独特的内容生态：
- 用户群体特征不同
- 内容消费习惯不同
- 算法推荐机制不同

### 主流平台特征

#### 小红书
- **用户画像**：女性为主（70%），18-35岁，一二线城市，消费力强
- **内容调性**：真实、种草、颜值、生活方式
- **最佳长度**：300-800字
- **关键因素**：封面图、标题、干货密度、标签
- **算法特点**：重视收藏率和互动率

#### 微信公众号
- **用户画像**：全年龄段，私域流量
- **内容调性**：深度、权威、情感共鸣
- **最佳长度**：1500-3000字
- **关键因素**：标题、开头、金句、排版
- **算法特点**：重视阅读完成率和转发

#### 抖音
- **用户画像**：全年龄段，下沉市场渗透高
- **内容调性**：娱乐、快节奏、冲突、情绪
- **最佳长度**：15-60秒（视频）
- **关键因素**：前3秒、音乐、热点
- **算法特点**：重视完播率和互动率

#### 知乎
- **用户画像**：高学历、职场人士
- **内容调性**：专业、理性、硬核
- **最佳长度**：1000-5000字
- **关键因素**：数据、逻辑、权威性
- **算法特点**：重视赞同率和专业认可

#### B站
- **用户画像**：Z世代为主，男女均衡
- **内容调性**：创意、真诚、二次元、社区感
- **最佳长度**：3-15分钟（视频）
- **关键因素**：选题、人设、弹幕互动
- **算法特点**：重视完播率和三连（点赞、投币、收藏）

#### 微博
- **用户画像**：广泛年龄层，热点敏感
- **内容调性**：快、热点、争议、情绪
- **最佳长度**：140字内（原生）
- **关键因素**：时效、话题、情绪
- **算法特点**：重视时效性和转发

#### X/Twitter
- **用户画像**：国际化、观点导向
- **内容调性**：观点、时效、简洁
- **最佳长度**：280字符内
- **关键因素**：话题、时机、互动
- **算法特点**：重视回复和转推

#### LinkedIn
- **用户画像**：职场人士、B2B决策者
- **内容调性**：专业、励志、职场洞察
- **最佳长度**：150-300词
- **关键因素**：故事、数据、行动号召
- **算法特点**：重视评论质量

### 评分量化标准

| 分数 | 标准 | 检查点 |
|-----|------|--------|
| 9-10 | 完美适配 | 格式、长度、调性、标签全部最优 |
| 7-8 | 良好适配 | 主要因素符合，1-2处可优化 |
| 5-6 | 基本适配 | 能发布但不利于推荐 |
| 3-4 | 较差适配 | 格式或调性明显不符 |
| 0-2 | 严重不适配 | 错误的平台选择 |

## 3. 写作质量 (Writing Quality) - 权重 15%

### 理论基础

综合多学科理论评估写作质量：

#### 社会学视角（2分）
- 是否触及社会热点或群体痛点
- 是否具有社会价值和公共意义

#### 心理学视角（2分）
- **说服心理学**：是否运用有效说服技巧
- **情绪心理学**：是否激发目标情绪反应
- **认知心理学**：是否降低认知负荷

#### 哲学视角（2分）
- 论述的逻辑严密性
- 观点的深度和原创性

#### 新闻学视角（2分）
- 信息准确性和客观性
- 结构清晰度（倒金字塔/叙事结构）

#### 传播学视角（2分）
- **STEPPS模型**：社交货币、触发器、情绪、公开性、实用价值、故事
- 是否易于二次传播

### 量化检查清单

每项通过得1分，总分10分：

| 检查项 | 说明 | 分值 |
|-------|------|------|
| 开头钩子 | 前3秒/首段能吸引注意力 | +1 |
| 结构清晰 | 有明确的分点或分段 | +1 |
| 金句记忆点 | 有1-2句可被记住的句子 | +1 |
| 语言流畅 | 无病句、错别字 | +1 |
| 观点明确 | 有清晰的立场和态度 | +1 |
| 情绪共鸣 | 能引发目标情绪 | +1 |
| 实用价值 | 读者能获得可操作的信息 | +1 |
| 逻辑自洽 | 论述前后一致，无矛盾 | +1 |
| 原创性 | 有独特视角或新颖表达 | +1 |
| 结尾有力 | 有总结、行动号召或留白 | +1 |

## 4. 互动潜力 (Engagement Potential) - 权重 18%

### 理论基础

基于社交媒体互动行为研究：

### 互动类型权重

| 类型 | 说明 | 用户心理 | 平台价值 |
|-----|------|---------|---------|
| 点赞 | 低成本认可 | 认同、欣赏 | 低 |
| 评论 | 中等参与 | 表达、讨论 | 高 |
| 收藏 | 功能性保存 | 实用、学习 | 中 |
| 转发 | 高成本传播 | 社交货币、共鸣 | 最高 |

### 高互动内容特征检查表

| 特征 | 权重 | 检查点 |
|-----|------|--------|
| 争议性话题 | 20% | 有讨论空间但不越界 |
| 实用干货 | 25% | 可保存、可操作 |
| 情感共鸣 | 25% | 感同身受、引发共情 |
| 社交货币 | 15% | 分享显得有品位/有见识 |
| 互动引导 | 15% | 结尾有明确互动话术 |

### 平台互动率基准

| 平台 | 优秀 | 良好 | 一般 | 较差 |
|-----|------|------|------|------|
| 小红书 | >8% | 4-8% | 2-4% | <2% |
| 微信公众号 | >3% | 1-3% | 0.5-1% | <0.5% |
| 抖音 | >10% | 5-10% | 2-5% | <2% |
| 知乎 | >5% | 2-5% | 1-2% | <1% |
| B站 | >8% | 4-8% | 2-4% | <2% |
| 微博 | >5% | 2-5% | 1-2% | <1% |

### 互动潜力评分标准

| 分数 | 标准 |
|-----|------|
| 9-10 | 具备爆款潜质，多项高互动特征 |
| 7-8 | 互动潜力良好，有1-2个亮点 |
| 5-6 | 一般内容，互动平平 |
| 3-4 | 缺乏互动点，较为平淡 |
| 0-2 | 无互动价值 |

## 5. 风险评估 (Risk Assessment) - 权重 15%

### 风险类型

| 风险类型 | 说明 | 影响 | 严重程度 |
|---------|------|------|---------|
| 平台合规 | 违反社区规则 | 限流/删除/封号 | 高 |
| 舆论风险 | 引发负面讨论 | 品牌声誉受损 | 高 |
| 法律风险 | 侵权/诽谤等 | 法律责任 | 极高 |
| 商业风险 | 损害商业利益 | 商业损失 | 中-高 |

### 风险红线清单（触发任一项即≤4分）

**平台合规红线**：
- 政治敏感内容
- 违规引流（私信加微信等）
- 未标注的广告/软文
- 抄袭搬运内容

**内容红线**：
- 虚假/误导信息
- 低俗/暴力内容
- 容貌/身材焦虑

**法律红线**：
- 版权侵权
- 肖像权侵权
- 隐私权侵权
- 诽谤/名誉侵权

**行业红线**：
- 医疗功效宣称
- 金融承诺（保本、收益等）
- 教育培训虚假宣传

### 风险等级评分

| 分数 | 风险等级 | 说明 | 行动 |
|-----|---------|------|------|
| 9-10 | 极低风险 | 无任何潜在风险点 | 可发布 |
| 7-8 | 低风险 | 有1-2处需注意但不影响发布 | 可发布，建议优化 |
| 5-6 | 中等风险 | 需要修改后发布 | 修改后发布 |
| 3-4 | 高风险 | 不建议发布 | 人工审核 |
| 0-2 | 极高风险 | 禁止发布 | 禁止发布 |

## 6. 事实核查 (Fact Check) - 权重 12%

### 核查流程

1. **识别**：标记内容中所有事实声明
2. **追溯**：查找原始数据来源
3. **验证**：交叉验证多个权威来源
4. **标注**：明确标注无法验证的声明

### 可靠来源等级

| 等级 | 来源类型 | 可信度 | 分值加成 |
|-----|---------|-------|---------|
| A | 官方数据、学术论文、权威机构 | 高 | +2 |
| B | 权威媒体、行业报告 | 中高 | +1 |
| C | 一般媒体、企业官网 | 中 | 0 |
| D | 自媒体、个人陈述 | 低 | -1 |

### 事实声明分类

| 类型 | 说明 | 核查要求 |
|-----|------|---------|
| 数据声明 | 具体数字、统计 | 必须有来源 |
| 引用声明 | 引用他人观点 | 需核实原文 |
| 因果声明 | A导致B | 需逻辑验证 |
| 时效声明 | 最新、第一等 | 需时间验证 |

### 评分标准

| 分数 | 标准 |
|-----|------|
| 9-10 | 所有声明可验证，来源权威 |
| 7-8 | 主要声明可验证，少数待确认 |
| 5-6 | 部分声明缺乏来源支撑 |
| 3-4 | 多处声明无法验证 |
| 0-2 | 存在明显错误信息 |

## 7. 时效性与热点 (Timeliness & Trends) - 权重 15% [新增]

### 理论基础

基于新闻传播学的时效性理论和社交媒体热点传播研究：
- 热点内容具有更高的初始曝光率
- 时效性内容的生命周期遵循特定曲线
- 差异化角度能延长内容生命周期

### 时效性分类

| 类型 | 说明 | 最佳发布时机 | 长尾价值 | 风险 |
|-----|------|-------------|---------|------|
| 热点追踪 | 紧跟当下热点 | 事件发生24h内 | 低 | 时效性风险 |
| 热点解读 | 深度分析热点 | 事件发生48-72h | 中 | 观点风险 |
| 常青内容 | 不受时间影响 | 任何时间 | 高 | 竞争风险 |
| 预测趋势 | 提前布局话题 | 趋势爆发前 | 高 | 判断风险 |

### 热点生命周期

```
      热度
        │
   ┌────┤     顶峰期 (发布窗口关闭)
   │    │    ╱╲
   │    │   ╱  ╲
   │    │  ╱    ╲ 衰退期 (追热点已晚)
   │    │ ╱      ╲
   │    │╱        ╲_______________
   │    ├─上升期────┼────────────────→ 时间
   │    │(最佳窗口)
   └────┴──────────────────────────────
        0   24h   48h   72h   7d
```

### 评估要素

| 要素 | 权重 | 说明 |
|-----|------|------|
| 热点关联度 | 30% | 内容与当前热点的相关性 |
| 时效窗口 | 25% | 是否在最佳发布时机内 |
| 差异化角度 | 25% | 是否有独特视角而非跟风 |
| 长尾价值 | 20% | 热点过后内容是否仍有价值 |

### 热点检测方法

1. **国内平台**：
   - 微博热搜榜
   - 抖音热榜
   - 小红书热门话题
   - 知乎热榜
   - B站热搜

2. **国际平台**：
   - X/Twitter Trending
   - Google Trends
   - Reddit Hot

3. **行业热点**：
   - 行业媒体头条
   - 竞品动态
   - KOL讨论

### 评分标准

| 分数 | 标准 | 说明 |
|-----|------|------|
| 9-10 | 完美时机 + 独特角度 | 热点上升期 + 差异化解读 |
| 9-10 | 高价值常青内容 | 不受时间影响的优质内容 |
| 7-8 | 时机合适 + 有差异化 | 热点期内 + 一定独特性 |
| 5-6 | 时机一般或角度同质化 | 热点衰退期或跟风内容 |
| 3-4 | 错过最佳时机 | 热点已过但仍在追 |
| 0-2 | 热点已过期 | 陈旧话题或过时信息 |

## 评分锚定示例

为确保评分一致性，每个分数段提供标准参考：

### 9-10分标杆特征
- 所有维度均无明显短板
- 至少2个维度达到9分以上
- 无任何风险红线触发
- 具备爆款潜质

### 7-8分标杆特征
- 大部分维度表现良好
- 1-2个维度需要小幅优化
- 风险可控
- 预期中等以上表现

### 5-6分标杆特征
- 基本合格但缺乏亮点
- 多个维度需要改进
- 可能存在中等风险
- 需要修改后发布

### 3-4分标杆特征
- 明显问题较多
- 存在高风险因素
- 不建议当前发布
- 需要大幅修改或重写

### 0-2分标杆特征
- 触发红线规则
- 存在严重问题
- 禁止发布
- 建议重新创作
