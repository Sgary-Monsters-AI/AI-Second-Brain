# 品牌配置文件目录 / Brand Configuration Directory

此目录用于存放品牌配置文件，支持在内容评估时选择或切换不同的品牌背景。

## 目录结构

```
brands/
├── README.md              # 本说明文件
├── _template.md           # 品牌配置模板
├── skincare-blogger.md    # 示例：护肤博主
├── tech-ceo.md            # 示例：科技CEO
└── lifestyle-kol.md       # 示例：生活方式KOL
```

## 使用方法

### 1. 创建新品牌配置

复制 `_template.md` 并按照模板填写你的品牌信息：

```bash
cp brands/_template.md brands/my-brand.md
```

### 2. 在评估时引用品牌配置

在请求评估时，指定品牌配置文件：

```
请评估以下内容：

【目标平台】小红书
【品牌配置】skincare-blogger
【内容草稿】
[在此粘贴内容]
```

或者直接引用文件路径：

```
请评估以下内容：

【目标平台】小红书
【品牌配置】brands/skincare-blogger.md
【内容草稿】
[在此粘贴内容]
```

### 3. 切换品牌配置

在同一会话中，可以随时切换不同的品牌配置：

```
切换品牌配置到 tech-ceo
```

或者在新评估请求中直接指定不同的品牌配置。

## 配置文件格式

品牌配置文件采用 Markdown 格式，包含以下核心部分：

| 部分 | 说明 | 必填 |
|-----|------|------|
| 品牌基础信息 | 品牌名称、类型、定位 | 是 |
| 品牌调性 | 文风、语言风格、情感基调 | 是 |
| 视觉调性 | 视觉风格指南（如适用） | 否 |
| 内容边界 | 能做/不能做的内容类型 | 是 |
| 平台策略 | 各平台的差异化策略 | 否 |

### dankoe 人设特别说明

`dankoe.md` 是一个特殊的品牌配置，用于生成 Dan Koe 风格的英文长文：

- **写作风格**：短句、直接、挑衅式开头、游戏/系统隐喻
- **文章长度**：3000-6000 词（大部分约 4000 词）
- **语言**：英文
- **封面图风格**：版画风格（engraving），内容需转换为超现实/科幻/神秘场景
- **发布平台**：X Articles
- **人设背景**：使用 james-en 的人设背景（Australian-based developer）

使用方法：
1. 在品牌配置选择时选择 `dankoe`
2. 或在平台选择时选择「dankoe 变体」

## 自定义品牌配置

根据你的需求，可以创建任意数量的品牌配置文件。建议：

1. **命名规范**：使用小写字母和连字符，如 `my-brand-name.md`
2. **完整填写**：尽可能填写所有字段，提升评估准确性
3. **定期更新**：随着品牌发展，及时更新配置文件
4. **多版本管理**：可为同一品牌创建不同场景的配置，如 `brand-formal.md` 和 `brand-casual.md`
