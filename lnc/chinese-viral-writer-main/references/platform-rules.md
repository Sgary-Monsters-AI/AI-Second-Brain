# 各平台标题与封面配文规则

---

## 通用规则

### 标题长度
- 目标：**15-25字**（中文）/ **8-15 words**（英文）
- 手机屏幕显示上限约20个中文字，超出会被截断
- 核心信息必须在前15字内完整呈现

### 封面配文
- 字数：**8-15字**（中文）/ **5-10 words**（英文）
- 必须能脱离标题独立传达情绪
- 视觉化 > 概念化（能在脑海中形成画面）
- 口语化 > 文案感（像人说话，不像广告）

### 标题与封面配文的关系
- **互补，不重复**：标题给信息钩子，封面配文给情绪冲击
- **各自独立**：单看标题能吸引点击，单看封面配文能传达态度
- **1+1>2**：组合后形成更强的点击驱动力

## 微信公众号

### 平台特性
- 标题在订阅号消息列表、朋友圈分享中展示
- 用户决策时间 < 1秒
- 朋友圈分享时只显示标题+缩略图，封面配文不可见

### 标题规则
- **字数**：15-22字最佳
- **前5字是黄金位置**：必须包含核心钩子
- 允许使用书名号《》引用影视/书籍
- 可以使用冒号制造悬念："[前置信息]：[核心爆点]"
- 不建议使用emoji（公众号调性偏正式）

### 封面配文规则
- 用于文章卡片的摘要位置
- 补充标题未说完的信息，或强化情绪
- 10-15字

### 适配策略
- 优先使用：对比法、数字法、好奇法、疑问法
- 哲学框架可以隐含但不要直接出现哲学家名字（受众太广）
- 情绪调性：可以重、可以猛，但要有"正当性"（不能纯标题党）

### 示例
```
标题：月入3万的金融男，都在吃9.9元的剩菜盲盒
封面配文：消费降级的真相
```

## X (Twitter) Articles 中文版

### 平台特性
- 标题在信息流中与推文混合展示
- 用户群体偏知识型、观点型
- 算法奖励引发讨论和引用的内容
- 长文标题+封面图同时展示

### 标题规则
- **字数**：15-25字
- 高信息密度：标题本身要有"观点浓度"
- 可以更锐利、更有态度（X用户容忍度更高）
- 可以直接使用哲学家名字或学术概念（受众匹配）
- 反常识和争议性标题在X上表现特别好

### 封面配文规则
- 用于文章卡片的副标题/描述位
- 可以比微信更短、更锐利
- 8-12字

### 适配策略
- 优先使用：疑问法、对比法、高赞评论法
- 哲学认知劫持框架在X上可以显性使用
- 鼓励观点鲜明、立场坚定（"站在一边"策略）
- 争议性标题会引发quote tweet，算法加权

### 示例
```
标题：你不是在奋斗，你在剥削自己 — 韩炳哲的警告
封面配文：停止自我奴役
```

## X (Twitter) Articles 英文版

### 平台特性
- 英文受众的阅读习惯和情绪触发不同
- 更重视specificity和data points
- 直接翻译中文标题通常效果不好，需要重新设计

### 标题规则
- **字数**：8-15 words
- 开头用强动词或数字
- 避免passive voice
- Specificity > Vagueness（"$80K" > "a lot of money"）
- 可以使用colon或em dash制造结构

### 封面配文规则
- 5-10 words
- 短语或祈使句优先
- 避免complete sentences

### 适配策略
- 英文标题不要直译中文，要重新构思
- 保留核心情绪和信息钩子，但用英文表达习惯重塑
- 数字法和对比法在英文中同样有效
- 哲学家名字在英文学术受众中更有号召力

### 示例
```
Title: Why Working Harder Makes You Poorer — Byung-Chul Han Was Right
Cover: Stop self-exploitation
```

## LinkedIn

### 平台特性
- 专业社交网络，调性偏商业和职业发展
- 用户期待"有见地的专业观点"
- 过度情绪化会降低可信度
- 长文以Newsletter或Article形式展示

### 标题规则
- **字数**：8-12 words（英文）
- 专业但不无聊
- 用insight代替emotion
- 可以使用行业术语（受众是专业人士）
- 避免clickbait感（LinkedIn用户对标题党反感度最高）

### 封面配文规则
- 5-8 words
- 偏专业洞察而非情绪表达
- Thought leadership调性

### 适配策略
- 优先使用：数字法（数据驱动）、疑问法（引发思考）
- 哲学框架以"framework"和"mental model"方式呈现，不要太文艺
- 核心情绪：好奇 > 向往 > 焦虑（LinkedIn不适合愤怒和恐惧）
- 标题要传达"读完你会获得竞争优势"

### 示例
```
Title: The Hidden Cost of Hustle Culture — A Framework for Sustainable Performance
Cover: Rethink productivity
```

## 小红书

### 平台特性
- 信息流以图片/视频+文字形式展示
- 标题和封面配文同时出现在封面上
- 用户年轻化，女性用户占比高
- 搜索权重高，标题需要考虑SEO关键词
- 平台对"标题党"有限流惩罚机制

### 标题规则
- **字数**：15-30字
- **前5字是黄金位置**（信息流只显示前半段）
- emoji使用：可以用但不超过2个（⚠️💡🔥⭐）
- 数字具象化："3年"比"多年"好，"80万"比"很多钱"好
- 关键词前置（影响搜索排名）

### 封面配文规则
- **8-12字**（太长会被截断）
- 必须能配合封面画面
- 可以是半句话（制造悬念）
- 四种常用句式：
  - 祈使句："别再[错误行为]"
  - 感叹句："这才是[正确答案]！"
  - 省略句："[核心词] + [情绪词]"
  - 对立句："[A] vs [B]"

### 适配策略
- 优先使用：数字法、好奇法、对比法
- 三种情绪路线（每组标题候选应覆盖）：
  - **攻击型**（戳痛点）：福柯+韩炳哲，愤怒→共鸣→点击
  - **诱惑型**（画大饼）：尼采+海德格尔，好奇→向往→点击
  - **共鸣型**（说心声）：拉康+列维纳斯，被理解→释放→点击

### 避坑指南
- ❌ 不用"震惊"、"必看"等词（会被限流）
- ❌ 不直接攻击具体公司/学校/导师（法律风险）
- ❌ 不过度贩卖焦虑（会被举报）
- ✅ 用"揭露逻辑"代替"道德批判"
- ✅ 用"我的经历"代替"普遍真理"

### 示例
```
标题：⚠️ 花80万留学回来月薪8000：没人告诉你的3个真相
封面配文：留学滤镜碎了
```
