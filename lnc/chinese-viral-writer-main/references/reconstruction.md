# 素材重构方法论

## 核心原则：维特根斯坦的语言游戏

维特根斯坦说：意义即用法。同一个思想，在不同的「语言游戏」中可以有完全不同的表达方式。

素材重构的本质，不是「换词」，而是「换游戏」。

你要做的是：
1. 提取原文的「思想内核」
2. 用全新的「语言游戏」重新表达这个内核
3. 让读者获得相同的认知冲击，但通过完全不同的路径

## 第一步：素材解构

### 1.1 提取核心论点

问自己：如果用一句话概括这篇文章想说什么，那句话是什么？

这句话应该是抽象的、本质的，而不是具体的。

**示例：**
- 原文讲了很多 AI 替代工作的例子
- 核心论点：「技术进步总是先淘汰中间层」

### 1.2 识别张力场

原文的两极对立是什么？

**示例：**
- 原文张力场：「AI 的美好承诺 vs. 打工人的焦虑」

### 1.3 拆解众生相

列出原文中所有的人物画像：
- 他们是什么群体？
- 在什么场景？
- 做了什么行为？

### 1.4 标记金句

找出原文中最有传播力的句子，通常是：
- 情绪扳机句
- 高度概括的断言
- 让人想截图的句子

### 1.5 画出结构骨架

原文的叙事顺序是什么？
- 开头用了什么钩子？
- 中间如何展开？
- 结尾如何收束？

## 第二步：重构策略

### 2.1 张力场迁移

**原则：保留张力的本质，更换张力的表象。**

**方法：**
- 同一个核心矛盾，换一个观察视角
- 或者，放大原文忽略的另一个张力维度

**示例：**
- 原文张力场：「AI 的美好承诺 vs. 打工人的焦虑」
- 新张力场：「人人都在谈 AI vs. 没人真的会用 AI」

### 2.2 众生相替换

**原则：100% 替换，0% 保留。**

**方法：**

对每个原文人物，进行三维替换：
1. **群体迁移**：程序员 → 设计师 → 翻译 → 客服
2. **场景迁移**：办公室 → 地铁上 → 深夜的出租屋 → 菜市场
3. **行为迁移**：保留行为的情绪本质，换掉具体动作

**示例：**
- 原文：「程序员凌晨两点还在调 bug」
- 重构：「设计师第八次改稿，甲方说还是第一版好」

两者的情绪本质相同（疲惫、无奈、被压榨），但具体呈现完全不同。

### 2.3 金句意义转译

**原则：保留认知冲击，更换语言容器。**

**维特根斯坦方法：找到金句的「逻辑形式」，用新的「语言游戏」重新填充。**

**操作步骤：**

1. 提取金句的逻辑骨架
2. 找到同构的生活隐喻
3. 用更简单、更口语的方式重新表达

**示例：**
- 原句：「当算法开始定义我们的欲望，我们就不再是欲望的主人」
- 逻辑骨架：「当 X 开始控制 Y，我们就失去了对 Y 的主权」
- 重构：「刷了两小时短视频才发现，我连自己想看什么都不知道了」

第二句更简单、更口语、更有画面感，但传递了相同的认知冲击。

### 2.4 结构重编

**原则：打乱原文顺序，重新组织叙事流。**

**常用重编手法：**

| 原文结构 | 重构结构 |
|---------|---------|
| 现象 → 分析 → 结论 | 结论先行 → 反问 → 现象佐证 |
| 多个并列案例 | 一个核心案例深挖 + 其他点到为止 |
| 时间顺序 | 空间并置（同一时刻不同人的状态） |
| 第三人称观察 | 第一人称体验 |
| 宏观到微观 | 微观切入，最后升华到宏观 |

## 第三步：执行重构

### 3.1 写作时的心理状态

把自己想象成：
- 你读过那篇文章
- 你被触动了
- 现在你要用「自己的话」跟朋友讲这件事
- 你会怎么讲？

这个心理状态能帮你自然地完成「语言游戏」的切换。

### 3.2 重构检查清单

写完后逐条检查：

**例子检查：**
- [ ] 每个人物的群体标签都换了？
- [ ] 每个场景都换了？
- [ ] 每个具体行为都换了？
- [ ] 没有任何一个例子能被指认出来源？

**结构检查：**
- [ ] 开头的钩子换了？
- [ ] 段落顺序打乱了？
- [ ] 收尾方式不同了？

**金句检查：**
- [ ] 每句金句都完成了意义转译？
- [ ] 新金句比原金句更简单？
- [ ] 新金句更口语化？

**整体检查：**
- [ ] 把两篇文章并排放，看不出师承关系？
- [ ] 给不知情的人看，无法猜到参考了哪篇？

## 多篇素材的融合重构

当输入是多篇文章时：

### 策略一：观点嫁接

从 A 文章取核心论点，从 B 文章取众生相，从 C 文章取结构。

### 策略二：张力叠加

A 文章的张力场 + B 文章的张力场 = 新的复合张力场。

### 策略三：众生相混编

从多篇文章中各取 1-2 个人物画像的「情绪本质」，全部用新的群体/场景/行为重新演绎。

## 底线原则

**可以借鉴的：**
- 思想内核
- 论证逻辑
- 情绪节奏
- 张力结构

**必须原创的：**
- 所有具体例子
- 所有金句的具体措辞
- 叙事结构的编排
- 第一人称的个人体验

**终极检验：**

如果原作者看到你的文章，他应该觉得「这个人和我想到一块去了」，而不是「这个人抄了我」。
