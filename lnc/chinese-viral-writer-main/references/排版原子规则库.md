## 第1章：人物名称格式

### 核心规则

所有出现的人物必须使用 Markdown 粗体格式 `**人物**`

### 加粗情况

✅ **必须加粗**：
- 具体人物称呼：**林风**、**老李**、**媳妇**、**老同学**、**司机**
- 有名有姓的人名
- 特定身份的人（**老板**、**房东**、**医生**）

### 不加粗情况

❌ **不需要加粗**：
- 第一人称「我」
- 泛指人物（有人、路人、某人）
- 动物或物品拟人化时

### 示例

```
✅ 正确格式：

**他**说，「移动硬盘摔了。」
**媳妇**问，「儿子发烧了，要不要去医院？」
接了一个**老同学**的电话。
房东**王姐**来消息了。

❌ 错误格式：

他说，「移动硬盘摔了。」（没加粗）
媳妇问，「儿子发烧了。」（没加粗）
老同学打电话来。（没加粗）
```

## 第2章：对话格式

### 核心规则

所有对话统一使用全角引号「」包裹

### 标准结构

```
**人物**说/问/讲，「对话内容」
```

### 格式规则

1. 对话内容用「」包裹
2. 人物称呼在引号外，需要加粗（除了「我」）
3. 保留「说」「问」「讲」等对话标签

### 示例

```
✅ 正确格式：

**他**说，「移动硬盘摔了，数据很重要。」
我问，「什么硬盘？」
**她**说，「西数的，里面是我拍的模特。」
我又问，「那要怎么办？」
**他**说，「你地址给我一下，我邮寄给你。」

❌ 错误格式：

他说，"移动硬盘摔了。"（用了英文引号）
她问，怎么了？（没有引号）
他说，移动硬盘摔了。（没有引号）
```

### 对话数量要求

每件事至少 **3-5个对话回合**，不能只陈述事件

```
❌ 错误：他说需要帮忙，我同意了。（只有一句）

✅ 正确：
**他**说，「这样吧，你再给我拿7万。」
我说，「容我思考一下。」
**他**说，「董俊峰，你知道我是很孤独的。」
我说，「我明白。」
**他**又说，「12正好是一个轮回，明年5月1我一次性给你。」
```

## 第3章：小标题规则

### 核心规则

**每一个事件/情节都必须有一个小标题**

### 格式要求

```
## 小标题（不加标点）

### 示例：
## 儿子发烧这事
## 老同学来借钱
## 色迷迷那个老哥
## 滴滴司机吵了一架
```

### 风格要求

- 口语化，5-10字
- 不加标点（不用句号、逗号、冒号）
- 有态度或有场景感
- 可以是人物特征、事件概括

### 正确/错误示例

```
✅ 正确：
儿子发烧这事
老同学来借钱
色迷迷那个老哥
滴滴司机绕路
说到底还是钱的问题

❌ 错误：
关于儿子生病的处理（太正式）
深度剖析借钱现象（太学术）
第一件事（太简单）
事件一（太抽象）
今天发生的事（太笼统）
```

### 数量规则

- 用户给几件事，文章就有几个小标题
- 不能合并、不能省略
- 每个事件必须有独立小标题

## 第4章：短句节奏

### 核心原则

短句为主，一句话一段很常见

### 句子长度限制

- 建议每句不超过 30 字
- 超过需拆分成长短句交替

### 允许的短句模式

```
✅ 短句示例：
很纠结。
算了。
没办法。
这事不行。
我挂了电话。
出了门。
刚坐下。

✅ 保留语气词：
这个事吧，你听我的就行了。
是呢，你说得对。
```

### 禁止长句

```
❌ 禁止：
他走后我望着他的背影还是有一丝小悲伤，想起曾经多么青春帅气的大男孩现在底气却不行了。

✅ 拆分为：
他走后，我望着他的背影。
还是有一丝小悲伤。
想起曾经多么青春帅气的大男孩。
现在底气却不行了。
```

## 第5章：标题规则

### 长度限制

标题长度：**64个汉字以内**

### 风格要求

- 概括当天核心事件或主题
- 可以有冲突感、故事感
- 口语化，不要文学腔
- 可以是一句完整的话

### 正确/错误示例

```
✅ 正确：
老同学找我借钱，我说没有
公司要认缴了，我把手续转给别人赚了点钱
儿子发烧，媳妇非要给他吃中药
色迷迷的老哥又来找我修硬盘
滴滴司机绕路，我给了第一个差评

❌ 错误：
今天杂记（太简单）
随笔（太简单）
深度思考：人性在金钱面前的复杂性（文学腔）
震撼！今天发生的三件事让我重新认识了这个世界（标题党）
```

## 检查清单

### 排版检查

- [ ] 所有人物名称加粗（除「我」）

- [ ] 标题64字以内

### 对话检查

- [ ] 每事件至少3-5个对话回合
- [ ] 对话使用标准结构：**人物**说/问，「内容」
- [ ] 保留语气词和停顿

### 节奏检查

- [ ] 短句为主，一句话一段
- [ ] 无超长句子（30字以内）
- [ ] 语气词自然使用
