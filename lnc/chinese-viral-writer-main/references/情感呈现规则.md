# 情感呈现规则

> 通过行为和对话呈现情感，不直接说感受。这是人类写作的核心特征，也是去AI味的关键。

---

## 核心理念

AI 写作的情感表达是「声明式」的：直接告诉读者「我感到XX」。

人类写作的情感表达是「展示式」的：通过具体的行为、对话、场景，让读者自己感受到情感。

**解决方案**：禁止直接说感受，必须通过行为和对话呈现。

---

## 规则索引

| 情感类型 | 禁止写法 | 正确写法 |
|----------|----------|----------|
| 反感 | 直接说「让我很反感」 | 通过行为呈现 |
| 纠结 | 直接说「我很纠结」 | 通过行为呈现 |
| 紧张 | 直接说「他很紧张」 | 通过行为呈现 |
| 开心 | 直接说「我很开心」 | 通过行为呈现 |
| 悲伤 | 直接说「很难过」 | 通过行为呈现 |

## 第1章：禁止直接说感受

### 声明式 vs 展示式

```
❌ 声明式（AI特征）：
让我很反感。
我很纠结。
他很紧张。
她很悲伤。
我觉得很不是滋味。

✅ 展示式（人类特征）：
电话一接通，听到他那声音，我就知道什么事。（呈现「反感」）
不见吧？同学，从小玩到大。我在门口站一会。算了，还是去见见吧。（呈现「纠结」）
从他进门到走，烟几乎一停没停。说话时手一直抖。（呈现「紧张」）
```

### 禁止的情感词汇

```
❌ 直接说感受的词汇：
让我很反感
我很纠结
他很紧张
她很悲伤
心里很不是滋味
感到欣慰
感到自豪
觉得无聊
很不是滋味
```

## 第2章：如何呈现反感

### 禁止写法

```
❌ 错误：
这让我很反感。
我对他的行为感到反感。
我觉得很反感。
```

### 正确写法

```
✅ 通过行为呈现：
电话一接通，听到**他**那声音。
我就知道什么事。
（一听声音就知道，说明是烦人的事）

✅ 通过对话呈现：
**他**说，「那个事，你再考虑一下。」
我说，「不考虑。」
（直接拒绝，不耐烦）
```

---

## 第3章：如何呈现纠结

### 禁止写法

```
❌ 错误：
我很纠结。
内心很纠结。
纠结要不要去。
```

### 正确写法

```
✅ 通过行为呈现：
不见吧？同学，从小玩到大。
见吧？大概率又是钱的问题。
上次借的5万还没还呢。
但是，同学归同学。
我在门口站一会。
算了，还是去见见吧。

（通过一系列内心活动和动作呈现「纠结」）
```

---

## 第4章：如何呈现紧张

### 禁止写法

```
❌ 错误：
他很紧张。
她看起来很紧张。
表现得非常紧张。
```

### 正确写法

```
✅ 通过行为呈现：
从**他**进门到走。
烟几乎一停没停。
说话时手一直抖。
茶倒出来了一些，**他**也没注意。

（通过具体的行为细节呈现「紧张」）
```

## 第5章：如何呈现其他情感

### 开心

```
❌ 错误：我很开心。/ 我感到很高兴。

✅ 正确：
**老婆**说，「中了！中了！」
我说，「多少？」
**她**说，「50万。」
我吼了一声。
（通过行为和对话呈现开心）
```

### 悲伤

```
❌ 错误：我很难过。/ 心里很悲伤。

✅ 正确：
挂了电话。
坐在那里。
不知道过了多久。
眼泪流下来。
（通过行为呈现悲伤）
```

### 无奈

```
❌ 错误：我觉得很无奈。/ 真的很无奈。

✅ 正确：
能怎么办？
只能这样了。
不这样的话，还有什么办法？
（通过对话呈现无奈）
```

---

## 第6章：关键原则

### 只呈现，不声明

```
❌ 不要说：我觉得很纠结
✅ 只呈现：不见吧？见吧？算了，还是去吧

❌ 不要说：我感到很开心
✅ 只呈现：吼了一声，跳起来
```

### 动作代替感受

```
用动作代替感受词：
纠结 → 站一会 / 算了 / 去吧
紧张 → 手抖 / 烟没停 / 茶洒了
开心 → 跳起来 / 吼一声 / 笑出声
```

### 对话呈现心理

```
直接的心理活动通过对话呈现：
内心想什么 → 嘴里说出来（或行动出来）
```

## 检查清单

### 逐项核对

- [ ] 无「让我很反感」
- [ ] 无「我很纠结」
- [ ] 无「他很紧张」
- [ ] 无「感到XX」「觉得XX」
- [ ] 所有情感通过行为呈现
- [ ] 所有心理活动通过对话/动作呈现
