# 风格模板生成器

> 将"感觉"翻译成"可执行规则"的系统方法论

## 方法论来源

基于「AI最严厉的父亲」文章的核心方法论：三Layer架构。

## 三层架构概览

```
┌─────────────────────────────────────────┐
│           风格提示词构成               │
├─────────────────────────────────────────┤
│                                         │
│  第一层：定义目标                        │
│  "请用XX风格写XX内容，XX感觉"            │
│                                         │
│  ────────────────────────────────────   │
│                                         │
│  第二层：制定规则                        │
│  标题规则 | 排版规则 | 句子规则 |      │
│  对话规则 | 禁用词 | 扩写技巧          │
│                                         │
│  ────────────────────────────────────   │
│                                         │
│  第三层：提供示例                        │
│  ✅ 正例 | ❌ 反例                   │
│                                         │
└─────────────────────────────────────────┘
```

## 第一层：目标定义

### 需要定义的元素

| 元素 | 问题 | 示例 |
|------|------|------|
| **输出格式** | 日记/随笔/论文/爆款？ | 日记体、随笔式 |
| **目标读者** | 谁在看？ | 中年男人、职场新人 |
| **核心感觉** | 读起来什么感觉？ | 真实、犀利、口语化 |
| **长度** | 多少字？ | 2000-3000字 |
| **平台** | 发在哪里？ | X Article、小红书 |

### 定义模板

```markdown
## 目标定义

- 输出格式：[日记/随笔/论文/爆款]
- 目标读者：[描述]
- 核心感觉：[3个关键词]
- 目标长度：[X字]
- 目标平台：[X/Twitter/小红书]
```

## 第二层：规则翻译

### 2.1 标题规则

**问题**：好标题vs坏标题长什么样？

| 好标题 | 坏标题 |
|--------|--------|
| 具体的一件事 | 概念合集 |
| 一句话能说完 | 总结性语句 |
| 口语化 | 书面语 |
| 有悬念 | 一眼看完 |

**规则模板**：

```markdown
### 标题规则

✅ 正确格式：
- [具体场景+结果]
- [第一人称叙述]

❌ 禁止格式：
- [深度思考：XXX]
- [震撼！XXX]
- [XX必须知道的X件事]
- [概念性标题]
```

### 2.2 排版规则

**问题**：目标风格用什么排版？

| 风格 | 引号 | 段落 | 加粗 | 特殊格式 |
|-------|------|------|------|----------|
| 大神日志 | 「」 | 短段落 | 人物名 | - |
| 小红书 | "" | 密集 | 无 | emoji |
| 公众号 | "" | 中等 | 关键词 | 空行 |
| 学术 | 「」 | 长段 | 术语 | 脚注 |

**规则模板**：

```markdown
### 排版规则

- 人物名称：加粗（**名字**）
- 对话引号：全角「」
- 段落长度：不超过X字
- 空行：每X段空一行
- 特殊标记：[其他]
```

### 2.3 句子规则

**问题**：句子长短、结构有什么特点？

**核心洞察**：AI句子太长太统一。

| 风格 | 平均句长 | 连接词 | 结构 |
|------|----------|-------|------|
| 大神日志 | <15字 | 少 | 变化 |
| 公众号 | 15-25字 | 适当 | 标准 |
| 小红书 | <20字 | 少 | 简单 |
| 学术 | 20-40字 | 多 | 复杂 |

**规则模板**：

```markdown
### 句子规则

- 最大句长：不超过X字
- 禁用连接词：
  - 然而、但是、因此
  - 首先、其次、最后
  - [风格特定词]
- 必须变化：
  - 句子长度有长短交替
  - 连接词不重复
```

### 2.4 对话规则

**问题**：需要对话吗？什么格式？

**核心洞察**：对话天然去AI味。

| 风格 | 需要 | 格式 |
|------|------|------|
| 大神日志 | 必须 | 「对话」 |
| 随笔 | 必须 | 「对话」 |
| 公众号 | 建议 | 「对话」 |
| 学术 | 无 | 引用格式 |

**规则模板**：

```markdown
### 对话规则

- 每件事必须有对话还原
- 对话轮数：每事X-Y轮
- 对话格式：全角引号「」
- 不能只陈述事件
```

### 2.5 修辞规则

**问题**：用什么修辞？禁用什么修辞？

**核心洞察**：AI太爱修辞，越禁止越自然。

| 风格 | 允许修辞 | 禁止修辞 |
|------|----------|----------|
| 大神日志 | 对比 | 比喻、排比、夸张 |
| 小红书 | 夸张 | 文学腔比喻 |
| 学术 | 无 | 所有修辞 |
| 公众号 | 适当 | 过度 |

**规则模板**：

```markdown
### 修辞规则

✅ 允许：
- 对比
- 拟人（适度）
- [其他]

❌ 禁止：
- 比喻（像/如同/仿佛/宛如）
- 排比（三个以上相同结构）
- 夸张（恨不得/简直）
- 设问/反问
- [风格特定]
```

### 2.6 禁用词清单

**问题**：有哪些AI高频词需要禁用？

**核心洞察**：这些词是AI的"指纹"。

#### AI通用高频词（全部风格）

```
❌ 然而、因此、此外、综上所述
❌ 值得深思、引人深思、发人深省
❌ 不禁让人想到、这让我意识到
❌ 首先...其次...最后...
❌ 总而言之、归根结底
❌ 彼时、此刻、涌现、萦绕
```

#### 风格特定词

```markdown
### 禁用词清单

**通用**（全风格禁用）：
- 见上方AI通用高频词

**医疗健康**：
- 颠覆认知、震惊、必看
- 众所周知、研究表明（空洞权威）
- 其实很简单（轻描淡写）

**商业财经**：
- 风口、赛道、红利期
- 轻松赚钱、稳赚

**生活方式**：
- 绝绝子、YYDS（网络黑话）
- 打卡、仪式感（过度使用）
```

### 2.7 情感呈现规则

**问题**：如何呈现情感？

**核心洞察**：Show don't tell。

| tell（说） | show（做） |
|-------------|------------|
| 我很纠结 | 烟一根接一根，手一直抖 |
| 他很紧张 | 说话结巴，不敢看我的眼睛 |
| 我很感动 | 眼眶红了，说不出话 |
| 她很开心 | 蹦起来拍手掌 |

**规则模板**：

```markdown
### 情感呈现规则

❌ 禁止直接说感受：
- 我很[情绪]
- 他很[情绪]
- 觉得[情绪]

✅ 必须通过行为呈现：
- [具体动作]
- [身体反应]
- [对话内容]
```

### 2.8 扩写技巧

**问题**：如何把短内容扩写成长内容？

**核心洞察**：质量扩写，不是数量扩写。

| 低质量扩写 | 高质量扩写 |
|------------|------------|
| 加更多修饰词 | 扩写对话 |
| 重复观点 | 扩写行为细节 |
| 升华总结 | 扩写心理活动 |
| 加废话 | 扩写背景信息 |

**规则模板**：

```markdown
### 扩写技巧

扩写方向（按优先级）：
1. 扩写对话（每事X-Y轮）
2. 扩写行为细节
3. 扩写心理活动
4. 扩写背景信息
5. 扩写关键观点

❌ 禁止：
- 加修饰词
- 重复观点
- 升华总结
- 加废话
```

## 第三层：示例

### 正反例格式

```markdown
## 示例库

### 标题

✅ 正例：
- 老同学找我借钱，我说没有
- 儿子发烧，媳妇非要给他吃中药

❌ 反例：
- 深度思考：人��在金钱面前的复杂性
- 震撼！今天发生的三件事让我重新认识了这个世界

---

### 对话

✅ 正例：
他说，「这样吧，你再给我拿7万。」
我说，「容我思考一下。」

❌ 反例：
他来找我借钱，我拒绝了，他有些失望地走了。

---

### 情感

✅ 正例：
从进来到走，烟几乎一停没停。手一直在抖，茶倒洒了都没注意。

❌ 反例：
他非常紧张，心里很纠结。
```

## 使用流程

### 步骤1：收集样本

找到目标风格的10篇以上代表作，仔细阅读。

### 步骤2：拆解元素

按上方模板逐一拆解：
- 标题特点
- 排版特点
- 句子特点
- 修辞特点
- 词汇特点

### 步骤3：列出清单

创建禁用词清单（通用 + 风格特定）。

### 步骤4：配示例

每条规则配正反例。

### 步骤5：测试迭代

生成内容 → 检查 → 调整 → 迭代。
