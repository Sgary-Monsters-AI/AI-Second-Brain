# 小红书社区规范合规指南

本文件整理了小红书官方社区规范和社区公约的核心要求，确保生成的内容和图片符合平台标准。

## 一、社区核心价值观

### 1.1 真诚分享

- **申明利益相关**：如有商业合作或利益关联，必须明确标注
- **抵制炫富**：不虚构或编造远超普通人的消费能力
- **反对伪科学**：只分享经过科学论证的内容
- **避免过度修饰**：真实呈现，不过度美化

### 1.2 友好互动

- 尊重他人及其劳动成果
- 鼓励普通人分享
- 避免辱骂、诋毁、嘲讽、威胁他人
- 不传播暴力恐怖、抹黑等恶意行为

## 二、内容禁止事项（红线）

### 2.1 绝对禁止的内容类型

| 类别 | 具体内容 |
|------|----------|
| **涉军涉政** | 警用/军用设备、涉及领导人、反动/政治体系、军事相关 |
| **违法违规物品** | 枪支弹药、违禁药品、管制刀具、保护动物、烟花爆竹 |
| **两性敏感** | 计生用品、性玩具、生殖健康、色情网站/APP |
| **烟草类** | 所有烟草相关产品和推广 |
| **封建迷信** | 风水、手相、塔罗牌、面相、算命 |
| **赌博类** | 所有赌博相关内容 |
| **裸露/性暗示** | 禁止发布裸露或性暗示内容（教育/医疗目的需严格遵守伦理规范） |

### 2.2 高风险限制内容

- 医美整形、医疗器械相关售卖内容
- 代购、转卖、拼单等营销倾向明显的内容
- 违背科学常识的内容（已被官方或权威机构辟谣的内容）

## 三、内容规范要求

### 3.1 原创与版权

**必须遵守：**
- 内容必须原创或已获授权
- 使用非原创素材必须进行二次创作并注明来源
- 禁止盗用、抄袭、侵权他人作品
- 禁止内容/图片相似性极高的搬运

**违规后果：** 限流、删除、封号

### 3.2 用语规范

**禁止绝对化用语：**
- 国家级、最高级、最佳、第一
- 史上最、顶级、绝对、100%
- 永远、必定、一定会

**禁止夸大功效承诺：**
- "一分钟见效"
- "吃完就变白"
- "3天瘦10斤"
- 其他无科学依据的效果承诺

**禁止诱导行为：**
- 直接或变相诱导关注/点赞/评论/收藏
- 如"双击屏幕有惊喜"、"评论666抽奖"

### 3.3 交易与导流规范（2025新规重点）

**核心要求：**
- 所有交易必须通过小红书官方渠道完成
- 禁止引导用户至第三方平台交易

**违规行为：**
- 传播联系方式/二维码
- 发布其他平台链接/水印
- 多账号协同导流
- 通过私信、评论、笔记、用户资料引导站外交易

**处罚：** 首次违规警告，情节严重者直接封号

**合规方式：** 仅认证企业号可使用官方"私信获客工具"（商家名片、留资卡等）

## 四、发布行为规范

### 4.1 禁止的发布行为

- 恶意批量注册账号
- 批量发布内容
- 高频发布（刷屏）
- 机器/脚本自动发布
- 其他非正常模式发布

### 4.2 正常发布建议

- 每日发布 1-3 篇为宜
- 间隔至少 2-4 小时
- 内容需有差异性
- 避免同质化内容

---

## 五、图片规范要求

### 5.1 图片内容规范

**禁止包含：**
- 其他平台水印或 logo
- 二维码、联系方式
- 低俗、猎奇画风
- 暴力恐怖元素
- 裸露或性暗示内容
- 侵权素材（未授权的明星、IP形象等）

**建议：**
- 风格与小红书社区调性一致（清新、真实、美好）
- 高清无水印
- 原创或已获授权
- 如使用 AI 生成，建议标注

### 5.2 封面图要求

- 比例：3:4（竖版）或 1:1（方形）
- 画质清晰，主体突出
- 文字不超过图片面积 20%
- 避免标题党式夸张文字

### 5.3 信息图/图文卡片规范

- 信息准确，有据可查
- 不包含绝对化用语
- 不夸大数据或效果
- 标注信息来源（如有）

## 六、内容风格合规指南

### 6.1 推荐的内容风格

| 特征 | 说明 |
|------|------|
| **真实分享** | 基于真实经历和感受 |
| **实用价值** | 对读者有帮助、有收获 |
| **积极正向** | 传递正能量，避免贩卖焦虑 |
| **通俗易懂** | 语言平实，普通人能看懂 |
| **友好互动** | 鼓励讨论，尊重不同观点 |

### 6.2 需要避免的内容风格

| 特征 | 说明 |
|------|------|
| **低俗猎奇** | 博眼球的不当画风 |
| **贩卖焦虑** | 制造恐慌、过度渲染危机 |
| **性别/群体对立** | 挑起对立情绪 |
| **虚假种草** | 未使用就推荐、夸大效果 |
| **拉踩抹黑** | 贬低其他品牌/产品/人物 |
| **恶意炫富** | 虚构消费能力、引发攀比 |

## 七、合规写作检查清单

### 发布前必查

**内容合规：**
- [ ] 不含绝对化用语（最、第一、顶级等）
- [ ] 不夸大功效或效果
- [ ] 不包含诱导关注/点赞的内容
- [ ] 不含违禁品或敏感话题
- [ ] 不含站外引流信息（二维码、微信号、链接等）
- [ ] 如有利益相关已明确标注

**原创合规：**
- [ ] 内容原创或已获授权
- [ ] 非原创素材已注明来源
- [ ] 图片不侵权（无未授权的明星/IP等）

**图片合规：**
- [ ] 无其他平台水印
- [ ] 无二维码/联系方式
- [ ] 风格符合社区调性
- [ ] 封面图清晰、主体突出

**用语合规：**
- [ ] 不含伪科学内容
- [ ] 不贩卖焦虑、不挑起对立
- [ ] 语言友好、尊重他人
- [ ] 不虚假炫富

## 八、违规处理等级

| 违规程度 | 处理措施 |
|----------|----------|
| 轻微 | 限流、内容不推荐 |
| 一般 | 删除笔记、警告 |
| 严重 | 账号限制功能、短期封禁 |
| 特别严重 | 永久封号、禁止登录 |

## 九、特定领域注意事项

### 9.1 科技/程序员内容

- 避免夸大技术收益（如"学这个月入百万"）
- 技术观点需有依据，避免绝对化表述
- AI 相关内容需客观，避免过度神化或妖魔化
- 工具推荐需基于真实使用体验

### 9.2 职场/成长内容

- 避免贩卖焦虑（如"30岁还没XX就完了"）
- 经验分享要真实，避免虚构履历
- 鼓励积极成长，避免打击读者信心
- 职业建议要负责任，说明适用条件

### 9.3 理财/副业内容

- 禁止承诺具体收益金额
- 不得推广违规金融产品
- 风险提示要充分
- 避免诱导投资或贷款
