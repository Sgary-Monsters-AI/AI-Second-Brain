# 零修辞原则

> 从修辞手法层面解决AI味，创作时强制加载，输出前逐项检查

---

## 核心理念

AI 最显著的「指纹」不是某个词汇，而是**修辞手法的滥用**。

人类写作时很少刻意使用修辞，但 AI 偏爱比喻、拟人、排比、夸张——因为这些是「写作」的典型特征。

**解决方案**：全面禁止修辞手法，回归白话叙事。

---

## 规则索引

| 修辞类型 | 禁用标识 | 替代方案 |
|----------|----------|----------|
| 比喻 | 像/如同/仿佛/宛如/好似 | 用具体行为描述 |
| 拟人 | 给抽象概念加动作 | 直接描述现象 |
| 排比 | 三个以上相同结构 | 自然长短句 |
| 夸张 | 恨不得/简直/快要 | 实事求是描述 |
| 反问/设问 | 难道...吗？真的...吗？ | 直接陈述 |

## 第1章：比喻禁用

### 禁用标识

```
❌ 像
❌ 如同
❌ 仿佛
❌ 宛如
❌ 好似
❌ 就像
❌ 如
```

### 错误示例

```
❌ 错误：
生活像一场戏
他的眼神如同刀锋
仿佛，一切都失去了意义
她就像一只受惊的小鹿
```

### 正确替换

```
✅ 替换为具体行为：
生活就是生活，该干嘛干嘛。
他的眼神很凶。
一切都失去了意义。
她很紧张，一直在抖。
```

### 唯一例外

**粗糙生活场景比喻**（无法用大白话说清时）

```
✅ 允许：
给拖拉机装触摸屏——这就是脱裤子放屁
像过年三十晚上的剩菜——反复热
```

## 第2章：拟人禁用

### 禁用规则

禁止给抽象概念添加人的动作

```
❌ 错误：
恐惧吞噬着内心
时间在流逝中消磨
记忆在脑海中翻涌
孤独侵蚀着灵魂

✅ 正确：
我感到恐惧
时间一点点过去
回忆起那些事
我很孤独
```

### 判断标准

如果主语是抽象概念（恐惧、时间、记忆、孤独、思念），且动词是人的动作（吞噬、消磨、翻涌、侵蚀），则为拟人。

## 第3章：排比禁用

### 禁用规则

禁止三个以上相同结构的句子连用

```
❌ 错误：
他很重要，她很重要，它们都很重要。
我们要努力，要奋斗，要拼搏。
因为A，因为B，因为C。

✅ 正确：
他很重要。她也是。它们都一样。
我们要努力。这很重要。
因为A。因为B。因为C，但不止这些。
```

### 变形检测

也要注意结构相似的排比句：

```
❌ 错误：
不仅是，而且是，更是
不但不，反而
既...又...又...
```

## 第4章：夸张禁用

### 禁用标识

```
❌ 恨不得
❌ 简直
❌ 快要
❌ 简直太
❌ 不要太
❌ 无比
❌ 超级
❌ 太太太
```

### 错误示例

```
❌ 错误：
简直太开心了
恨不得马上冲过去
快要气死了
不要太爽
```

### 正确替换

```
✅ 替换为实事求是描述：
挺开心的。
马上冲过去。
很生气。
挺爽的。
```

---

## 第5章：反问/设问禁用

### 禁用标识

```
❌ 难道...吗？
❌ 真的...吗？
❌ 难道不是吗？
❌ 真的假的？
❌ 真的吗？
❌ 不是说...吗？
```

### 错误示例

```
❌ 错误：
难道我们不应该努力吗？
真的有人会相信吗？
难道你不想成功吗？
真的是这样吗？
```

### 正确替换

```
✅ 替换为直接陈述：
我们应该努力。
有人会相信。
你想成功。
是这样的。
```

## 第6章：其他修辞禁用

### 省略号滥用

```
❌ 错误：
我想说......但最终还是没有说......
命运的齿轮......

✅ 正确：
我想说，但最终没说。
命运就是这样。
```

### 破折号滥用

```
❌ 错误：
这是一个——重要的——决定
他——一个普通人——做出了不凡的事

✅ 正确：
这是一个重要的决定。
他一个普通人，做出了不凡的事。
```

## 检查清单

### 逐项核对

- [ ] 无「像」「如同」「仿佛」「宛如」
- [ ] 无给抽象概念加动作
- [ ] 无三个以上相同结构
- [ ] 无「恨不得」「简直」「快要」
- [ ] 无反问/设问句式
- [ ] 无省略号滥用
- [ ] 无破折号滥用
