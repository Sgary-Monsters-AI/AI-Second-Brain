# 模型温度配置指南

> 如何配置模型温度以降低AI味

## 温度是什么

温度（Temperature）是LLM的核心参数之一，控制输出的随机性：

| 温度 | 效果 | 适用场景 |
|------|------|----------|
| 0.0-0.3 | 确定性输出，最"正确"但最像AI | 代码、事实问答 |
| 0.7-1.0 | 默认值，安全但平庸 | 日常对话 |
| 1.0-1.35 | 推荐区间，输出更自然 | 内容创作 |
| 1.35-1.5 | 高创意，但可能不稳定 | 创意写作 |
| >1.5 | 开始胡说八道 | 不推荐 |

## 温度与AI味的关系

**核心洞察**：AI味来自"太正确"——每一个词都在该出现的位置上，没有意外。

- 低温（<1.0）：输出四平八稳，AI味重
- 适温（1.2-1.35）：有变化感，像人写的
- 高温（>1.5）：开始失控，胡言乱语

**推荐温度**：1.35 是经过测试的平衡点。

## 按模型推荐

| 模型 | 推荐温度 | 说明 |
|------|---------|------|
| **Gemini 2.5 Pro** | 1.35 | 创意写作最佳，配合提示词效果最好 |
| **Claude 4 Opus** | 1.2-1.3 | 创意能力强，温度可低 |
| **Claude 4 Sonnet** | 1.2-1.3 | 均衡选择 |
| **GPT-4o** | 1.2 | 默认稍低，需调高 |
| **GPT-4o mini** | 1.15 | 小模型建议保守 |
| **Kimi** | 1.1 | 国内模型建议保守 |
| **通义千问** | 1.1 | 国内模型 |
| **文心一言** | 1.0-1.1 | 国内模型 |

## 配置方式

### 方式1：API调用时配置

```python
# OpenAI
response = client.chat.completions.create(
    model="gpt-4o",
    temperature=1.35,
    messages=[...]
)

# Anthropic
response = client.messages.create(
    model="claude-sonnet-4-20250514",
    temperature=1.2,
    messages=[...]
)

# Google
response = model.generate_content(
    prompt,
    generation_config={
        "temperature": 1.35
    })
```

### 方式2：客户端配置

推荐使用 **Cherry Studio**，支持温度可视化配置：

- 下载：https://cherry-soft.com
- 配置位置：设置 → 模型 → 高级选项

### 方式3：网页版临时方案

如果使用网页版无法配置温度：

1. 在提示词中明确指定：
   ```
   请用更高的创意度写作，允许使用非标准表达，
   可以有轻微的不完美，允许偶尔出格。
   ```

2. 分层生成：
   - 先生成大纲（低温，确保逻辑）
   - 再逐段生成（高温，增加人味）

## 温度微调技巧

### 如果AI味依然重

1. **温度加0.1**，逐步测试
2. 在提示词中添加：
   ```
   允许句子长度有变化。
   允许用口语化表达。
   允许偶尔用重复词。
   ```

### 如果输出开始失控

1. **温度减0.1**
2. 在提示词中添加约束：
   ```
   但保持基本逻辑连贯。
   不要偏离主题。
   ```

### 特殊情况

| 场景 | 建议温度 | 说明 |
|------|---------|------|
| 金句/标题 | 1.4-1.5 | 需要出其不意 |
| 长文主体 | 1.2-1.3 | 保持连贯 |
| 收尾升华 | 1.3-1.4 | 需要情感强度 |
| 对话还原 | 1.0-1.1 | 需要准确性 |

## 检查清单

使用温度配置后，检查输出：

- [ ] 句子长度有变化
- [ ] 有意想不到的表达
- [ ] 没有过度"正确"的感觉
- [ ] 读起来像人在说话
- [ ] AI检测工具分数降低
