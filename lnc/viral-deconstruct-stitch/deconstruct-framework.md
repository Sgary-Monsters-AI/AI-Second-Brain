# 爆款拆解框架：7维 Viral DNA 模型

> 版本：1.0 | 2026-02-24
> 用途：对任意爆款内容提取结构化病毒DNA，供缝合引擎使用

---

## 核心原则

提取的是**心理机制**，不是内容本身。

- ✅ 合法：提取"用数据制造认知冲击"这个机制
- ❌ 洗稿：复制"年入千万 vs 年入百万的老板区别"这个具体框架

---

## 7维拆解模型

### 维度1：Hook DNA

**目标**：识别开头如何在3秒内抓住注意力

| 子维度 | 说明 | 提取格式 |
|--------|------|----------|
| Hook类型 | 数据型/情绪型/反常识型/故事型/问题型/身份型 | 单选 |
| 触发词 | 具体触发注意力的词汇或句式模式 | 3-5个词 |
| 认知缺口 | 制造了什么"我需要知道答案"的悬念 | 一句话描述 |
| 身份锚定 | 是否明确指向特定人群（"如果你是X"） | 是/否+描述 |

**输出示例**：
```
Hook类型：数据型
触发词：年入千万、区别、老板
认知缺口：成功者和普通人的差距到底在哪
身份锚定：是，锚定创业者/想赚钱的人
```

---

### 维度2：张力结构

**目标**：识别内容如何维持读者持续阅读的动力

| 子维度 | 说明 |
|--------|------|
| 冲突类型 | 现实vs期望 / 常识vs真相 / 我vs他人 / 过去vs现在 |
| 张力维持方式 | 悬念递进 / 反转堆叠 / 情绪升温 / 信息密度 |
| 认知缺口数量 | 全文制造了几个"我想知道答案"的节点 |
| 解决节奏 | 快速解决（爽文型）/ 延迟解决（悬念型）/ 部分解决（留钩型） |

---

### 维度3：论证模式

**目标**：识别内容如何让观点显得可信

| 模式 | 特征 | 适用场景 |
|------|------|----------|
| 归纳型 | 多个案例→得出规律 | 经验分享、规律总结 |
| 演绎型 | 原理→推导结论 | 认知升级、方法论 |
| 类比型 | A像B，所以A也有B的特性 | 复杂概念解释 |
| 对比型 | X vs Y，突出差异 | 选择建议、认知纠偏 |
| 权威型 | 引用数据/研究/名人 | 增加可信度 |
| 亲历型 | 我自己经历了X | 真实感、共鸣 |

提取：主要论证模式 + 辅助论证模式

---

### 维度4：收尾类型

**目标**：识别结尾如何完成情绪闭环并触发传播

| 类型 | 特征 | 传播效果 |
|------|------|----------|
| 方法论型 | 给出可执行步骤 | 收藏率高 |
| 认知颠覆型 | 最后一句推翻前面的假设 | 转发率高 |
| 情感共鸣型 | 说出读者心里的话 | 评论率高 |
| 行动号召型 | 明确要求读者做某事 | 互动率高 |
| 开放悬念型 | 留下未解答的问题 | 关注率高 |

---

### 维度5：情绪弧线

**目标**：识别全文的情绪流动路径

常见弧线模式：
- **好奇→共鸣→顿悟**：认知升级类内容
- **愤怒→认同→行动**：社会议题类内容
- **焦虑→希望→方法**：解决方案类内容
- **怀疑→惊讶→信服**：反常识类内容
- **共鸣→痛点→解脱**：情感治愈类内容

提取：起点情绪 → 中间转折点 → 终点情绪

---

### 维度6：病毒触发器

**目标**：识别触发分享/转发的心理机制

| 触发器 | 机制 | 识别特征 |
|--------|------|----------|
| FOMO | 害怕错过重要信息 | "你不知道就亏了" |
| 身份认同 | 转发=表达自我 | "这说的就是我" |
| 认知失调 | 打破已有认知 | "原来我一直错了" |
| 社会证明 | 别人都知道我也要知道 | 数据/案例堆叠 |
| 利他动机 | 分享给需要的人 | 实用信息+明确受众 |
| 优越感 | 我知道别人不知道的 | 内部信息/独家视角 |

提取：主要触发器（1-2个）+ 次要触发器

---

### 维度7：格式模式

**目标**：识别影响阅读体验的格式特征

| 子维度 | 提取内容 |
|--------|----------|
| 总字数 | 估算范围（短<500/中500-1500/长>1500） |
| 段落节奏 | 短句密集型 / 长短交替型 / 长段叙述型 |
| 标点风格 | 感叹号频率 / 省略号使用 / 破折号使用 |
| 数字使用 | 高频数字型 / 低频数字型 |
| 对话感 | 强（直接问读者）/ 弱（陈述为主） |
| 列表使用 | 有序列表 / 无序列表 / 无列表 |

## DNA卡片输出格式

每篇爆款拆解后输出标准DNA卡片：

```markdown
## DNA卡片：[标题]

**来源**：[平台] | [博主] | [日期] | [互动数据]
**话题**：[核心话题标签]

### Hook DNA
- 类型：[类型]
- 触发词：[词1、词2、词3]
- 认知缺口：[一句话]
- 身份锚定：[是/否+描述]

### 张力结构
- 冲突类型：[类型]
- 维持方式：[方式]
- 认知缺口数：[数字]
- 解决节奏：[类型]

### 论证模式
- 主要：[模式]
- 辅助：[模式]

### 收尾类型
[类型] + 一句话说明为什么有效

### 情绪弧线
[起点] → [转折] → [终点]

### 病毒触发器
- 主要：[触发器] — [具体体现]
- 次要：[触发器] — [具体体现]

### 格式模式
- 字数：[范围]
- 节奏：[类型]
- 对话感：[强/弱]

### Roland视角
[这篇内容对Roland创作的启发，必须原创，不能复制内容]
```

## 使用说明

1. 每次拆解一篇，生成一张DNA卡片
2. DNA卡片保存到 `01-内容生产/素材库/爆款文稿库/DNA数据库/`
3. 同时更新 `dna_index.json` 索引
4. 拆解完3篇以上后可进入缝合流程
