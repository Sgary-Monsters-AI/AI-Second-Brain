# 缝合规则：从DNA到内容蓝图

> 版本：1.0 | 2026-02-24
> 用途：定义如何合法地将多份DNA缝合成新内容蓝图

---

## 核心区分

| | 洗稿（违法/违规） | 合法缝合 |
|--|-----------------|---------|
| 复制什么 | 具体内容、例子、比喻、数据 | 心理机制、结构模式、情绪逻辑 |
| 来源 | 单一来源 | 3-5篇混合提取 |
| 原创性 | 无 | 必须加入Roland独特视角 |
| 话题 | 相同话题 | 可以是全新话题 |

---

## 防洗稿硬性规则（不可违反）

**规则1**：禁止复制具体素材
- 禁止：复制原文的例子、数据、比喻、故事
- 允许：提取"用数据制造认知冲击"这个机制，用新数据实现

**规则2**：单一来源限制
- 从任何单一来源提取的结构元素，连续使用不超过3个维度
- 即：不能把某篇文章的Hook+张力+论证全部照搬

**规则3**：Roland原创视角强制注入
- 最终蓝图必须包含≥2个Roland独有的视角/经历/观点
- 这些视角不能从任何来源DNA中找到

**规则4**：相似度检验
- 最终输出与任何单一来源的结构相似度 <30%
- 检验方法：对比7个维度，相同维度不超过2个

---

## 缝合策略

### 输入要求
- 最少3篇DNA，最多5篇
- 建议：同一话题领域的不同角度，或不同话题但相似受众

### 选取逻辑

**Step 1：识别最强元素**

从所有DNA中，按维度选出表现最强的：

| 维度 | 选取标准 |
|------|----------|
| Hook DNA | 互动数据最高的那篇的Hook类型 |
| 张力结构 | 认知缺口数量最多且解决节奏最优的 |
| 论证模式 | 与Roland话题最匹配的模式 |
| 收尾类型 | 与本次创作目标（收藏/转发/评论）匹配的 |
| 情绪弧线 | 与目标受众情绪状态最匹配的 |
| 病毒触发器 | 与Roland品牌定位最一致的 |
| 格式模式 | 目标平台最优格式 |

**Step 2：Roland视角注入**

在蓝图中标记2-3个"Roland原创注入点"：
- 个人经历/观察
- 独特的跨领域类比（如：用科研视角看商业）
- 反直觉的个人立场

**Step 3：话题迁移（可选）**

如果要把A话题的DNA用到B话题：
- 保留：心理机制、情绪弧线、论证模式
- 替换：所有具体内容、例子、数据
- 检验：B话题的受众是否会被同样的机制触发

## 蓝图输出格式

```markdown
## 内容蓝图：[拟定标题]

**生成日期**：[日期]
**目标平台**：[平台]
**目标受众**：[描述]
**创作目标**：[收藏率/转发率/评论率/涨粉]

### DNA来源
- 来源1：[标题] — 提取：[提取了什么维度]
- 来源2：[标题] — 提取：[提取了什么维度]
- 来源3：[标题] — 提取：[提取了什么维度]

### 防洗稿校验
- [ ] 无具体素材复制
- [ ] 单一来源维度 ≤3个
- [ ] Roland原创视角 ≥2个
- [ ] 结构相似度 <30%

### 蓝图结构

**Hook**（来源：[DNA来源] 的[Hook类型]机制）
[具体Hook方向，不是原文，是新的实现方式]

**张力设计**（来源：[DNA来源] 的张力结构）
[如何在本文制造冲突/认知缺口]

**论证路径**（来源：[DNA来源] 的论证模式）
[论证逻辑框架，用Roland自己的素材填充]

**Roland原创注入点**
- 注入点1：[位置] — [内容方向]
- 注入点2：[位置] — [内容方向]

**情绪弧线**（来源：[DNA来源]）
[起点] → [转折] → [终点]
[每个节点的具体情绪设计]

**收尾设计**（来源：[DNA来源] 的收尾类型）
[收尾方向，不是原文]

**格式规范**
- 字数目标：[范围]
- 段落节奏：[类型]
- 平台特殊要求：[要求]

### 关键词/金句方向
[3-5个方向，供写作时参考]
```

---

## 质量检查清单

蓝图完成后，逐项确认：

- [ ] Hook能在3秒内制造认知缺口
- [ ] 张力能维持读者读完全文
- [ ] 论证逻辑自洽，不依赖原文素材
- [ ] Roland视角真实、独特、不可替代
- [ ] 情绪弧线完整，有起有落
- [ ] 收尾完成情绪闭环
- [ ] 格式符合目标平台规范
- [ ] 防洗稿四项规则全部通过
