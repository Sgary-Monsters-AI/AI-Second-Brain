# 分诊系统扩展指南

> 如何根据你的需求，添加新的分诊分类

---

## 为什么需要扩展

**默认的 6 大分类**覆盖了常见场景，但每个人都有独特的工作流：

- 投资人需要**投资研究**分类
- 律师需要**案件管理**分类
- 教师需要**课程设计**分类
- 研究员需要**文献管理**分类

---

## 扩展原则

### 何时添加新分类

| 信号 | 说明 | 建议动作 |
|------|------|----------|
| **频繁误判** | 某类内容经常被分到错误类别 | 考虑独立分类 |
| **数量庞大** | 某类内容超过总内容的 20% | 建议独立分类 |
| **特殊工作流** | 有独特的处理流程 | 需要独立分类 |
| **权限隔离** | 需要与其他内容隔离 | 必须独立分类 |

### 何时不添加新分类

- 可以用标签区分的（不要新建分类）
- 数量很少（<5%）的（用现有分类+标签）
- 临时性的（用"稍后处理"）

---

## 扩展步骤

### 步骤 1：确定需求

**问自己 3 个问题**：

1. **是什么类型的内容？**
   - 描述具体内容
   - 举例说明

2. **与其他分类有什么不同？**
   - 处理方式不同？
   - 存储位置不同？
   - 后续动作不同？

3. **使用频率如何？**
   - 每天多次？
   - 每周几次？
   - 每月几次？

**示例**：
```
我是投资人，经常收集：
- 公司财报
- 行业研报
- 投资笔记

这些内容现在被分到"03-学习/"，但：
- 需要特殊的投资分析框架
- 后续要生成投资决策
- 需要跟踪标的表现

频率：每天 3-5 个

→ 建议新建"07-投资研究/"
```

---

### 步骤 2：设计分类结构

**模板**：

```markdown
### {编号}-{分类名称} | `{编号}-{分类名称}/`

**用途**：一句话描述

**判断标准**（满足 X条+）：
- [ ] 条件1
- [ ] 条件2
- [ ] 条件3

**存储结构**：
```
{编号}-{分类名称}/
├── 📄 _index.md
├── 📁 子目录1/
└── 📁 子目录2/
```

**后续动作**：
- 动作1
- 动作2
```

**示例（投资研究）**：

```markdown
### 07-投资研究 | `07-投资研究/`

**用途**：投资标的分析、财报研究、投资决策

**判断标准**（满足 1条+）：
- [ ] 公司财报/年报
- [ ] 行业研究报告
- [ ] 投资分析笔记
- [ ] 标的信息/新闻
- [ ] 投资策略/方法

**存储结构**：
```
07-投资研究/
├── 📄 _index.md
├── 📁 01-财报分析/
│   └── {公司名}-{日期}/
│       ├── 原始财报.md
│       ├── 分析笔记.md
│       └── 决策记录.md
├── 📁 02-行业研究/
├── 📁 03-投资笔记/
└── 📁 04-标的数据/
```

**后续动作**：
- 创建投资分析框架
- 关联已有标的
- 设置跟踪提醒
- 生成投资决策
```

### 步骤 3：创建目录结构

**执行命令**：

```bash
cd ~/AI-Admin-System

# 创建主目录
mkdir -p 07-投资研究/{01-财报分析,02-行业研究,03-投资笔记,04-标的数据}

# 创建索引文件
cat > 07-投资研究/_index.md << 'EOF'
# 07-投资研究

投资研究资料管理。

## 目录结构

- 01-财报分析/ - 公司财报和分析
- 02-行业研究/ - 行业研究报告
- 03-投资笔记/ - 投资思考和决策
- 04-标的数据/ - 标的信息跟踪

## 工作流程

1. 收集资料 → 分诊到此目录
2. 分析研究 → 填写分析框架
3. 生成决策 → 记录投资决策
4. 跟踪复盘 → 定期更新数据
EOF
```

## 扩展最佳实践

### 1. 渐进式扩展

```
第 1 周：使用默认分类
    ↓ 发现某类内容频繁
第 2 周：尝试用标签区分
    ↓ 发现还是混乱
第 3 周：创建新分类
    ↓ 验证效果
第 4 周：完善规则和模板
```

### 2. 记录扩展原因

在 `记忆库/语义记忆/分诊扩展日志.md` 记录：

```markdown
## 2026-03-18 添加 07-投资研究

**原因**：
- 投资资料每周 10+ 个
- 误判率高（常被分到学习）
- 需要特殊的分析框架

**结构**：
- 01-财报分析
- 02-行业研究
- 03-投资笔记
- 04-标的数据

**效果**（1周后评估）：
- 误判率：30% → 5%
- 分诊效率：提升
```

### 3. 定期清理

每月检查：
- 是否有空分类？
- 是否有可以合并的分类？
- 分类使用率是否均衡？
