# 快速上手指南

安装完成后，按照本指南快速掌握核心功能。

## 日常启动流程

每天第一次使用时：

```bash
cd ~/AI-Admin-System
claude
```

```
你: 启动 AI 助手

AI: ✓ 上下文：XXXX/200000 (X%) [正常]

    📅 今日：2026-03-18

    🔴 紧急任务（P0）：1 个
       - [ ] 完成项目报告（今天截止）

    🟡 近期截止（7天内）：2 个
       - [ ] 准备会议材料（周五截止）
       - [ ] 回复客户邮件（明天截止）

    ❓ 今天有要分诊的内容吗？
```

## 核心场景

### 场景 1: 记录新想法

当你看到一篇好文章或产生一个想法时：

```
你: 有，我要分诊一篇文章
AI: 请粘贴内容或描述你的想法
你: [粘贴文章内容]

AI: 📋 分诊结果
    ├─ 分类：01-内容生产/
    ├─ 评级：A类（高适配）
    ├─ 主题：AI 发展趋势
    ├─ 存储位置：2026-03-18-AI发展趋势/
    └─ 建议：适合改写成长文

    已保存，是否开始创作？

你: 是
AI: [进入内容生产流程]
```

### 场景 2: 创建任务

当你想到需要做的事情时：

```
你: 我需要下周三前完成调研报告
AI: ✅ 已创建任务
    ├─ 任务：完成调研报告
    ├─ 截止日期：下周三（2026-03-25）
    └─ 优先级：P1

    已记录到任务清单.md
```

### 场景 3: 查看任务

随时查看当前任务状态：

```
你: 启动 AI 助手
AI: [自动输出任务简报]
```

完成任务后：

```
你: 任务「完成调研报告」已完成
AI: ✅ 已标记完成
    已将 [ ] 改为 [x]
```

### 场景 4: 内容创作

对于已分诊的内容：

```
你: 进入下一步
AI: [继续创作流程]

或

你: 我想创作关于 XXX 的内容
AI: [启动创作流程]
```

## 常用指令

| 指令 | 作用 |
|------|------|
| `启动 AI 助手` | 启动系统，查看简报 |
| `今天有要分诊的内容吗` | 启动内容分诊 |
| `进入下一步` / `继续` | 继续当前工作流 |
| `commit` | 提交 Git 更改 |
| `/clear` | 清理上下文（卡顿时使用）|

## 最佳实践

### 1. 每日启动

每天早上启动系统，查看任务简报：

```bash
cd ~/AI-Admin-System && claude
启动 AI 助手
```

### 2. 及时分诊

看到好文章或产生想法时，立即分诊：

```
今天有要分诊的内容
```

### 3. 定期回顾

每周回顾一次：
- 清理已完成的任务
- 整理情景记忆到语义记忆
- 更新任务优先级

### 4. 持续积累

在 `语义记忆/` 中添加你的：
- 写作风格指南
- 常用决策框架
- 领域专业知识
- 工作流程模板

| `/clear` | 清理对话历史，释放上下文 |

## 故障排除

### 上下文满了

```
AI: ⚠️ 上下文使用率超过 60%，建议清理

你: /clear
```

### 忘记当前任务

```
你: 启动 AI 助手
AI: [自动输出当前任务状态]
```

### 需要查看历史

```bash
# 查看对话历史
cat 对话历史.md

# 查看任务清单
cat 任务清单.md
```

## 进阶技巧

### 批量处理

```
你: 帮我分诊这 3 篇文章
[粘贴文章1]
---
[粘贴文章2]
---
[粘贴文章3]
```

### 自定义规则

在 `.claude/rules/` 添加你自己的规则：

```markdown
# 05-my-rules.md

## 我的工作习惯

- 每天早上 9 点检查邮件
- 下午 2-5 点是深度工作时间
- 周五下午做周总结
```

### 使用 Git 管理版本

```bash
# 每天结束时提交
git add .
git commit -m "daily: $(date +%Y-%m-%d)"

# 查看历史
git log --oneline
```
