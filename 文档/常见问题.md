# 常见问题（FAQ）

## 安装问题

### Q: Claude Code 安装失败？

**错误信息**：`npm ERR! permission denied`

**解决方案**：
```bash
# macOS/Linux: 使用 sudo
sudo npm install -g @anthropic-ai/claude-code

# 或修改 npm 权限
sudo chown -R $(whoami) $(npm config get prefix)/{lib/node_modules,bin,share}

# Windows: 以管理员身份运行 PowerShell
# 右键 → 以管理员身份运行
```

---

### Q: 安装后输入 `claude` 提示命令不存在？

**解决方案**：
```bash
# 检查是否添加到 PATH
which claude

# 如果没有输出，手动添加
export PATH="$PATH:$(npm config get prefix)/bin"

# 永久添加（添加到 ~/.zshrc 或 ~/.bashrc）
echo 'export PATH="$PATH:$(npm config get prefix)/bin"' >> ~/.zshrc
source ~/.zshrc
```

---

### Q: 模板安装后启动报错？

**错误信息**：`找不到规则文件`

**解决方案**：
1. 确认在正确的目录启动
   ```bash
   cd ~/AI-Admin-System
   pwd  # 确认路径正确
   ```

2. 检查规则文件是否存在
   ```bash
   ls .claude/rules/
   # 应该看到 00-typography.md 等文件
   ```

3. 如果缺少文件，重新复制模板

## 使用问题

### Q: 启动后没有输出简报？

**可能原因**：
- 任务清单.md 格式错误
- 规则文件加载失败

**解决方案**：
```bash
# 检查任务清单格式
cat 任务清单.md

# 确保格式正确
## 🔴 紧急重要（P0）

### [ ] 任务名称
- **任务**：描述
- **优先级**：P0
```

---

### Q: AI 没有自动捕获任务？

**可能原因**：
- 没有触发信号词
- 规则未加载

**解决方案**：
1. 使用信号词：
   - "我需要..."
   - "记得..."
   - "待办..."

2. 明确指令：
   ```
   记录下来：我需要周五前完成报告
   ```

---

### Q: 内容分诊不准确？

**解决方案**：
1. **提供更多上下文**
   ```
   这是一篇关于 XXX 的文章，我想用来发公众号
   ```

2. **手动指定分类**
   ```
   这个放到 03-学习/ 下面
   ```

3. **迭代改进规则**
   ```
   以后这类内容都分到 01-内容生产/
   ```

---

### Q: 中文排版没有生效？

**可能原因**：
- 规则文件未加载
- 缓存问题

**解决方案**：
1. 检查规则是否存在
   ```bash
   ls .claude/rules/00-typography.md
   ```

2. 重启 Claude Code
   ```
   /clear
   退出重新进入
   ```

3. 手动触发规则
   ```
   请按照中文排版规范检查这段文字
   ```

## 性能问题

### Q: Claude Code 响应很慢？

**解决方案**：
1. **清理上下文**
   ```
   /clear
   ```

2. **压缩上下文**
   ```
   /compact
   ```

3. **检查上下文使用率**
   ```
   查看回复开头的 ✓ 上下文：XX%

   如果 >50%，建议清理
   ```

4. **减少加载文件数量**
   - 避免在启动时读取大文件
   - 分批次处理内容

---

### Q: API 费用很高？

**优化建议**：
1. **减少文件读取**
   - 不要一次性读取整个目录
   - 按需读取特定文件

2. **使用 /compact**
   - 定期压缩上下文
   - 减少 token 消耗

3. **批量处理**
   - 合并相关任务
   - 减少对话轮数

## 数据问题

### Q: 如何备份数据？

**方案 1：Git 备份（推荐）**
```bash
cd ~/AI-Admin-System
git init
git add .
git commit -m "backup: $(date +%Y-%m-%d)"
git push origin main
```

**方案 2：云同步**
```bash
# 使用 iCloud（macOS）
mv ~/AI-Admin-System ~/Library/Mobile\ Documents/com~apple~CloudDocs/
ln -s ~/Library/Mobile\ Documents/com~apple~CloudDocs/AI-Admin-System ~/AI-Admin-System

# 使用 Dropbox
mv ~/AI-Admin-System ~/Dropbox/
ln -s ~/Dropbox/AI-Admin-System ~/AI-Admin-System
```

**方案 3：定时备份脚本**
```bash
#!/bin/bash
# backup.sh

cd ~/AI-Admin-System
git add .
git commit -m "auto backup: $(date +%Y-%m-%d-%H:%M)"
git push origin main
```

添加到 crontab：
```bash
# 每天 18:00 自动备份
0 18 * * * /path/to/backup.sh
```

### Q: 误删了文件如何恢复？

**解决方案**：
1. **Git 恢复**
   ```bash
   # 查看历史
   git log --oneline

   # 恢复特定文件
   git checkout HEAD~1 -- 文件路径

   # 恢复到指定版本
   git checkout abc123 -- .
   ```

2. **从归档恢复**
   ```bash
   # 检查 _Archive/ 目录
   ls _Archive/

   # 移动回原位
   mv _Archive/文件名.md 原位置/
   ```

### Q: 如何迁移到新电脑？

**步骤**：
1. **旧电脑**：推送所有更改
   ```bash
   cd ~/AI-Admin-System
   git add .
   git commit -m "migrate: 准备迁移"
   git push
   ```

2. **新电脑**：克隆仓库
   ```bash
   git clone https://github.com/yourname/AI-Admin-System.git
   cd AI-Admin-System
   ```

3. **安装 Claude Code**
   ```bash
   npm install -g @anthropic-ai/claude-code
   ```

4. **启动使用**
   ```bash
   claude
   启动 AI 助手
   ```

## 进阶问题

### Q: 如何创建自己的 Skill？

**步骤**：
1. 创建目录
   ```bash
   mkdir -p .claude/skills/my-skill
   ```

2. 编写 SKILL.md
   ```markdown
   # my-skill

   功能描述

   ## 触发词
   - "触发词"

   ## 使用方法
   使用说明
   ```

3. 使用 Skill
   ```
   /my-skill
   ```

详细教程参考：[创建自定义 Skill](./创建自定义Skill.md)

---

### Q: 如何修改系统规则？

**建议**：
1. **不要修改默认规则**
   - 默认规则（00-04）是系统基础
   - 修改可能导致不可预期问题

2. **添加自定义规则**
   - 创建 `05-my-rules.md`
   - 创建 `06-custom-behavior.md`

3. **覆盖规则**
   - 在 CLAUDE.md 中添加补充说明
   - 在语义记忆中定义个人偏好

### Q: 如何与其他工具集成？

**Obsidian**：
1. 打开 Obsidian
2. 选择 "打开文件夹"
3. 选择 `~/AI-Admin-System`
4. 安装推荐插件：
   - Dataview（数据查询）
   - Templater（模板）
   - Git Integration（版本控制）

**Notion**：
- 使用 Notion Web Clipper 保存网页
- 导出 Markdown 后分诊到系统

**Zotero**：
- 文献管理用 Zotero
- 笔记和写作用本系统
- 通过 `03-学习/` 关联
