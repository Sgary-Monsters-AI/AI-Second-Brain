# AI 第二大脑系统 - 安装指南

## 系统要求

- **操作系统**: macOS 12+ / Windows 10+ / Linux
- **内存**: 建议 16GB+
- **Node.js**: 18+
- **存储空间**: 至少 1GB 可用空间

## 第一步：安装 Claude Code

Claude Code 是本系统的核心工具。

### macOS

```bash
# 使用 npm 安装
npm install -g @anthropic-ai/claude-code

# 或使用 Homebrew
brew install claude-code
```

### Windows

```powershell
# 使用 npm 安装（需要管理员权限）
npm install -g @anthropic-ai/claude-code
```

### Linux

```bash
# 使用 npm 安装
npm install -g @anthropic-ai/claude-code
```

**验证安装**:

```bash
claude --version
```

## 第二步：安装 AI 第二大脑系统

### 方式一：使用安装脚本（推荐）

1. **下载模板**

   ```bash
   # 克隆仓库
   git clone https://github.com/yourusername/AI-Second-Brain.git
   cd AI-Second-Brain
   ```

2. **运行安装脚本**

   ```bash
   # 使用默认名称（AI-Second-Brain）
   ./install.sh

   # 或使用自定义名称
   ./install.sh AI-MyName
   ```

   脚本会自动：
   - 复制模板到 `~/AI-Second-Brain`（或 `~/AI-MyName`）
   - 更新系统名称
   - 清理临时文件

### 方式二：手动安装

1. **创建目录**

   ```bash
   mkdir ~/AI-Second-Brain
   cd ~/AI-Second-Brain
   ```

2. **复制模板文件**

   手动复制以下文件到目标目录：
   - `CLAUDE.md`
   - `README.md`
   - `任务清单.md`
   - `对话历史.md`
   - `.gitignore`
   - `.claude/rules/` 目录下的所有文件
   - `记忆库/强制规则/` 目录下的所有文件
   - `01-内容生产/` 目录结构

3. **个性化配置**

   编辑 `CLAUDE.md`，将 "AI 助手" 改为你喜欢的名称：

   ```markdown
   # 修改前
   你是 **AI 助手**，用户的 AI 数字分身。

   # 修改后
   你是 **AI_Alice**，Alice 的 AI 数字分身。
   ```

## 第三步：首次启动

1. **进入目录**

   ```bash
   cd ~/AI-Second-Brain
   ```

2. **启动 Claude Code**

   ```bash
   claude
   ```

3. **启动 AI 助手**

   在 Claude Code 中输入：

   ```
   启动 AI 助手
   ```

   系统会自动：
   - 加载所有规则文件
   - 读取任务清单
   - 输出今日简报
   - 询问是否有内容要分诊

## 第四步：验证安装

测试以下功能是否正常：

### 1. 测试内容分诊

```
你: 今天有要分诊的内容
AI: 请粘贴内容
你: 这是一篇关于人工智能的文章...
AI: [应该自动分类到 01-内容生产/]
```

### 2. 测试任务追踪

```
你: 我需要在周五前完成报告
AI: [应该自动创建任务并记录到任务清单.md]
```

### 3. 测试中文排版

```
你: 写一句包含中英文的话
AI: [应该自动在中文和英文之间加空格]
```

## 常见问题

### Q: Claude Code 安装失败？

**A**: 检查 Node.js 版本：

```bash
node --version  # 需要 v18+
```

如果版本过低，先升级 Node.js：

```bash
# macOS
brew upgrade node

# 或使用 nvm
nvm install 20
nvm use 20
```

### Q: 启动时提示找不到规则文件？

**A**: 确保你在正确的目录启动：

```bash
cd ~/AI-Second-Brain
claude
```

### Q: 如何修改系统名称？

**A**: 编辑 `CLAUDE.md` 文件：

```bash
# 使用你喜欢的编辑器
vim ~/AI-Second-Brain/CLAUDE.md
# 或
code ~/AI-Second-Brain/CLAUDE.md
```

找到并修改：

```markdown
你是 **AI_新名称**，用户的 AI 数字分身。
```

### Q: 如何备份我的数据？

**A**: 使用 Git：

```bash
cd ~/AI-Second-Brain
git add .
git commit -m "备份: $(date +%Y-%m-%d)"
git push origin main
```

或使用云同步（Dropbox/iCloud）：

```bash
# 将目录移动到 iCloud
mv ~/AI-Second-Brain ~/Library/Mobile\ Documents/com~apple~CloudDocs/

# 创建软链接
ln -s ~/Library/Mobile\ Documents/com~apple~CloudDocs/AI-Second-Brain ~/AI-Second-Brain
```
