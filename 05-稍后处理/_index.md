# 05-稍后处理

> 暂时无法分类的内容，等待进一步决策

---

## 说明

当内容无法立即确定分类时，先放在这里：

- 需要更多信息才能判断
- 暂时不确定如何处理
- 需要与他人讨论后再决定
- 分类模糊，需要思考

---

## 定期回顾

**建议频率**：每周一次

**回顾检查清单**：
- [ ] 本周新增了多少待处理内容？
- [ ] 这些内容现在可以分类了吗？
- [ ] 哪些可以归档？
- [ ] 哪些需要进一步行动？

---

## 处理流程

```
稍后处理中的内容
    ↓
定期回顾（每周）
    ↓
├─ 可以分类了 → 移动到正确分类
├─ 无需处理 → 移动到 06-归档/
└─ 仍需等待 → 保留，设置下次回顾时间
```
