# dna

文风 DNA 编解码技能：分析写作样本，生成个人文风 DNA 编码报告。

---

## 触发词

- "/dna"
- "文风模版"
- "帮我制定文风"
- "分析我的文风"
- "文风 DNA"
- "编码我的文风"

---

## 前置读取（必须）

每次触发时，按顺序读取以下文件：

1. **编解码手册**：`lnc/chinese-viral-writer-main/references/文风DNA编解码手册v3.0.md` — 编码规则和格式定义
2. **品牌配置模板**：`lnc/chinese-viral-writer-main/brands/_template.md` — 品牌配置的标准字段
3. **已有编码报告**（参考风格）：
   - `lnc/chinese-viral-writer-main/brands/Grace文风DNA完整编码.md`
   - `lnc/chinese-viral-writer-main/brands/B哥文风DNA编码报告.md`

---

## 功能

1. 收集用户的写作样本（至少 3 篇，建议 5 篇以上）
2. 按照《文风DNA编解码手册v3.0》的 7 层编码体系分析样本
3. 生成完整的文风 DNA 编码报告
4. 生成品牌配置文件（基于 `_template.md`）
5. 保存到 `lnc/chinese-viral-writer-main/brands/` 目录

---

## 流程

### 阶段一：收集样本

向用户收集写作样本，说明要求：

```
要为你做文风 DNA 编码，需要你的写作样本。

要求：
- 至少 3 篇，建议 5 篇以上（样本越多，编码越准）
- 选择你认为最能代表你风格的作品
- 可以是文章、推文、公众号文章、社交媒体帖子等任何形式
- 粘贴文字内容，或提供文件路径/链接

准备好了就发给我。
```

### 阶段二：逐层编码分析

读取《文风DNA编解码手册v3.0》，严格按照以下 7 层依次分析：

| 层级 | 编码 | 分析内容 |
|------|------|----------|
| 1 | PH | 哲学层：平均句长、本体论类型、时间观 |
| 2 | EP | 认识论：知识来源、验证方式、真理观 |
| 3 | ID | 意识形态：7 个维度各 1-9 评分 |
| 4 | RH | 修辞层：论证方式、修辞手法、节奏类型 |
| 5 | SY | 句法层：句长、复杂度、标点风格、句式比例 |
| 6 | DN | 领域编码：词汇专业度、术语比、口语比、领域码 |
| 7 | RD | 六维雷达：真实性、权力性、情感性、逻辑性、具体性、行动性 |

每一层必须：
- 给出编码值
- 用样本中的原文举例佐证
- 参考 Grace 和 B 哥的编码报告的格式和深度

### 阶段三：提取话语模式

从样本中提取 5-10 个高频话语模式（PT），格式：

```
PT01(XX%): "{模板}" | 示例: "{样本原文}"
```

### 阶段四：构建词汇库

根据用户的写作领域，整理 8 类词汇：
- 核心概念词、人物/品牌词、方法/工具词、问题/现象词
- 效果/目标词、特征/属性词、专业术语词、口语/俚语词

### 阶段五：识别算法和规则

- 从样本中识别 2-3 个常用内容算法（AL）
- 提取 5-10 条特殊写作规则（RULE）
- 识别 3-5 个核心矛盾点（CD）

### 阶段六：输出与保存

生成两个文件：

1. **文风 DNA 编码报告**：`{用户名}文风DNA编码报告.md`
   - 包含完整 6 层编码 + 话语模式 + 词汇库 + 算法 + 规则 + 矛盾点
   - 格式参考 Grace 和 B 哥的编码报告

2. **品牌配置文件**：`{用户名}.md`
   - 基于 `_template.md` 的格式
   - 填入从 DNA 编码中提炼的品牌调性信息

两个文件都保存到 `lnc/chinese-viral-writer-main/brands/`

## 注意事项

1. 编码必须严格遵循《文风DNA编解码手册v3.0》的格式定义
2. 每个编码值都必须有样本原文作为证据支撑
3. 样本不足 3 篇时提醒用户补充，但不拒绝分析
4. 分析过程中如发现样本间风格差异大，需要主动提出并讨论
5. 保存文件前确认用户认可编码结果
6. 已有编码报告时，询问用户是更新还是新建
