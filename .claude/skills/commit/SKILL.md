# commit

自动分析变更内容，生成规范的 commit message，支持按目录分组提交。

---

## 触发词

- "commit"
- "提交"
- "保存更改"

---

## 功能

1. 自动检测变更文件
2. 分析变更内容类型
3. 生成符合 Conventional Commits 规范的提交信息
4. 按目录分组提交（可选）
5. 支持确认模式（先展示再提交）

---

## 使用方法

### 基础用法

```
你: commit

AI: 检测到以下变更：
    - 新增: 文档/安装指南.md
    - 修改: README.md
    - 删除: 临时文件.txt

    建议提交信息：
    docs: 添加安装指南，更新 README

    是否提交？(是/否/修改)
```

### 按目录分组提交

```
你: 按目录分组提交

AI: 将按以下分组提交：

    组 1 - 文档更新：
    - 文档/安装指南.md
    - 文档/快速上手指南.md
    提交信息：docs: 添加安装和快速上手指南

    组 2 - 配置更新：
    - .claude/rules/00-typography.md
    提交信息：config: 更新中文排版规范

    是否提交？(是/否)
```

---

## Commit 类型前缀

| 前缀 | 用途 | 示例 |
|------|------|------|
| `feat:` | 新功能 | feat: 添加内容分诊功能 |
| `fix:` | 修复 | fix: 修复任务追踪遗漏 |
| `docs:` | 文档 | docs: 更新安装指南 |
| `config:` | 配置 | config: 更新排版规则 |
| `content:` | 内容 | content: 添加新文章 |
| `refactor:` | 重构 | refactor: 优化目录结构 |
| `archive:` | 归档 | archive: 移动已完成任务 |

---

## 注意事项

1. 提交前会自动检查是否有敏感信息
2. 大文件（>10MB）会提醒确认
3. 删除操作会额外确认
4. 支持 `--dry-run` 模式预览变更
