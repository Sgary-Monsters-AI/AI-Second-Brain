# 内容生产引擎1 (Engine 1 Launch)

**快捷命令**：`/lnc` 或 `启动内容生产引擎1`

> 情绪冲击模式：筛选 → 创作 → 保存 → 输出，四阶段门控的完整内容生产工作流。
> **模块化配置**：可拆卸、可组装，支持多版本销售

---

## 配置文件

> 仅管理员可修改，定义销售包内容

**配置位置**：`config/`

| 文件 | 作用 |
|------|------|
| `presets.json` | 预设销售版本（定义完整包） |
| `stages.json` | 开启哪些阶段 |
| `platforms.json` | 包含哪些平台 |

## 第0阶段：品牌加载 + 配置确认

启动时首先选择品牌配置：

**可用品牌**（共4个，全部展示）：
- `模板` — 品牌配置模板（复制后自定义）
- `dankoe` — Dan Koe 商业个人品牌风格（参考案例）
- `banfo` — 半佛仙人：戏谑犀利的商业分析风格
- `自定义` — 创建新品牌配置

**品牌配置位置**：`chinese-viral-writer-main/brands/`

**创建新品牌**：
如需创建新品牌配置，复制 `_template.md` 文件到同名位置，按模板填写即可。模板包含：品牌基础信息、品牌调性、语言风格、情感基调、视觉调性、内容边界、平台差异化策略等完整字段。

---

### ⚡ 配置确认（必须）

> 去AI味优化 - 本阶段必须确认

**温度配置**：
| 场景 | 推荐模型 | 推荐温度 |
|------|---------|----------|
| 长文创作 | Gemini 2.5 Pro | 1.35 |
| 长文创作 | Claude 4 | 1.2-1.3 |
| 国内模型 | Kimi | 1.1 |

> 配置方式：
> - API：在调用时加 `temperature: 1.35`
> - Cherry Studio：设置 → 模型 → 高级选项

**禁用词清单**：
> 参考 `chinese-viral-writer-main/brands/brand-forbidden-words.md`

> 创作时自动应用品牌禁用词清单

**阶段门检查**：
```
✅ 第0阶段完成，检查清单：
   - 品牌配置已选
   - 温度已配置（或已知）
   - 模型已确认
```

## 第1阶段：筛选阶段

**目标**：判断内容是否值得投入资源创作

**执行内容**：`content-filter/` 或 `content-filter/.claude/skills/`

**评估维度**（7维度）：
1. 品牌一致性 (0-10)
2. 平台匹配度 (0-10)
3. 写作质量 (0-10)
4. 互动潜力 (0-10)
5. 风险评估 (0-10)
6. 事实核查 (0-10)

**阶段门检查**：
```
✅ 筛选阶段完成，检查清单：
   - 综合评分 ≥ 9.0（A级≥8.5可进入创作但建议优化）
   - 无红线问题（事实错误/法律风险/品牌冲突）
   - 平台选择明确

进入创作阶段。
```

**判定结果**：
- **A**：立即创作（评分≥8.5，直接进入创作）
- **B**：优化后创作（评分7.0-8.4，需优化后才能进入创作）
- **C**：放弃或大改（评分<7.0，或存在红线问题）

## 第2阶段：创作阶段

### 创作前确认（素材完整性）

**目标**：确保创作前素材完整，防止虚构内容

**时机**：筛选通过后，创作开始前

**执行流程**：

#### 1. 素材清单确认

```
□ 用户提供了几个素材/事件？
□ 每个素材包含哪些要素？
  - 时间（早上/下午/2023年春节）
  - 地点（书店门口/XX办事处）
  - 人物（具体称呼）
  - 事件（发生了什么）
  - 对话（可有可无）
```

#### 2. 素材完整性评估

| 完整性等级 | 说明 | 处理方式 |
|------------|------|----------|
| **完整** | 包含时间/地点/人物/事件 | 可直接创作 |
| **部分完整** | 缺少部分要素 | 需向用户确认或合理推演 |
| **不完整** | 缺少核心要素（事件） | 返回补充素材 |

#### 3. 虚构风险检查

```
□ 用户是否明确要求虚构/改编？
□ 素材中的对话是否完整？（不完整需推演）
□ 素材中的细节是否足够？（不够需确认）
```

**阶段门检查**：
```
✅ 素材确认完成，检查清单：
   - 素材数量已确认
   - 素材完整性已评估
   - 虚构风险已排查

进入内容创作。
```

### 内容创作

**目标**：产出符合品牌标准的原创内容

**前置检查（创作前）**：
```
⏩ 创作前确认：
□ 温度已配置（1.2-1.35）
□ 模型已确认
□ 输入包含个人素材/数据点？（避免只有主题）
□ 禁用词清单已加载
```

**执行流程**：

#### 2.1 战略规划
- 使用四维武器库设计内容架构
  - 哲学维度：意向性锚点、权力意志、框架劫持
  - 心理学维度：原型激活、认知偏误、情绪触发
  - 传播学维度：AIDA 漏斗、社交货币、叙事传输
  - 社会学维度：文化模因、身份认同、社会证明

#### 2.2 内容创作
- 执行：`chinese-viral-writer-main/`
- 或使用：`chinese-viral-writer-main/`
- **禁用词清单已自动应用**

### 2.3 自评检查
- 从读者视角评分（0-10）
- 目标：≥9.0 才能通过

### 2.4 创作后检查 + 去AI味处理（必须）

创作完成后，必须逐项检查以下内容：

#### A. 排版检查（12条）
```
□ 无"然而""因此""此外"
□ 无"值得深思""引人深思"
□ 无"首先...其次...最后..."
□ 无"这就是..."升华结尾
□ 无"彼时""此刻""涌现"
□ 无空洞权威词
□ 无营销号词汇
□ 无说教感词汇
□ 句子长度有变化
□ 对话有引号（「」）
□ 无破折号滥用
□ 无三段式滥用
```

#### B. 零修辞检查（6条）
```
□ 无比喻词（像/如同/仿佛/宛如）
□ 无拟人（给抽象概念加动作）
□ 无排比（三个以上相同结构）
□ 无夸张（恨不得/简直/快要）
□ 无反问/设问（难道...吗？）
□ 无省略号/破折号滥用
```
**参考**：`零修辞原则.md`

#### C. 情感呈现检查（5条）
```
□ 无直接说感受（"我很XX"）
□ 反感通过行为呈现
□ 纠结通过行为呈现
□ 紧张通过行为呈现
□ 心理活动通过对话/动作呈现
```
**参考**：`情感呈现规则.md`

#### D. 排版原子规则检查（4条）
```
□ 所有人物名加粗（除"我"）
□ 每事件有独立小标题
□ 对话用「」全角引号
□ 短句为主，无超长句
```
**参考**：`排版原子规则库.md`

#### E. humanizer-zh 处理
- 执行：`humanizer-zh/` 或手动处理
- 参考：`brand-forbidden-words.md` 核对禁用词

**阶段门检查**：
```
✅ 创作阶段完成，检查清单：
   - 自评 ≥ 9.0
   - 排版检查12条通过
   - 零修辞检查6条通过
   - 情感呈现检查5条通过
   - 排版原子规则检查4条通过
   - humanizer-zh 处理已完成
   - RLHF 记录已更新

进入保存阶段。
```

### 2.6 RLHF 记录
- 记录创作决策到品牌配置目录下的迭代日志
- 标注：高分规则、低分原因、探索模式

**阶段门检查**：
```
✅ 创作阶段完成，检查清单：
   - 自评 ≥ 9.0
   - 排版检查12条通过
   - 零修辞检查6条通过
   - 情感呈现检查5条通过
   - 排版原子规则检查4条通过
   - humanizer-zh 处理已完成
   - RLHF 记录已更新

进入保存阶段。
```

## 第3阶段：保存阶段

**目标**：将内容正确归档到内容生产系统

**保存位置**（用户本地笔记库路径，按需调整）：
```
01-内容生产/选题管理/02-待发布/[YYYY-MM-DD-标题]/
├── 元文章.md          # 完整原文 + 元数据
├── prompts.json       # 配图提示词
├── 发布版本/          # 各平台适配版本
└── 传播素材/          # 标题、封面、金句
```

**阶段门检查**：
```
✅ 保存阶段完成，检查清单：
   - 元文章已保存到正确位置
   - prompts.json 已生成
   - 目录结构完整

进入输出阶段。
```

## 第4阶段：输出阶段

**目标**：生成发布就绪的平台版本

**支持平台**：
- 微信公众号 (`发布工具/wechat-publisher/`)
- X Articles (`发布工具/x-publisher/`)
- LinkedIn (`发布工具/linkedin-publisher/`)
- 小红书 (`发布工具/xiaohongshu-images/`)

**输出前检查**（镜头检查）：
- 服务读者比例 ≥ 60%（vs 自我表达）
- 标题吸引力评分
- CTA 清晰度
- 配图完整性

**阶段门检查**：
```
✅ 输出阶段完成，检查清单：
   - 镜头检查已执行
   - 平台版本已生成
   - 传播素材已就绪

内容发布就绪。
```

## 阶段门汇总

| 阶段 | 阶段门 | 编号 |
|------|--------|------|
| 品牌加载 | 品牌配置已选 + 温度已确认 | 0.1-0.3 |

## 退出工作流

**正常退出**：完成所有4个阶段后，内容进入发布队列

**中途退出**：
- 输入 `/exit` 或 `退出`
- 当前进度会保存到 `01-内容生产/选题管理/01-待深化/`（用户本地笔记库路径，按需调整）

**重置工作流**：
- 输入 `/reset` 清空当前上下文
