# triage

智能内容分诊系统：自动分类新输入到对应目录。

---

## 触发词

- "/triage"
- "分诊"
- "今天有要分诊的内容吗"
- "帮我分类这个"

---

## 功能

1. 分析输入内容（文章/想法/链接/文件）
2. 根据分诊规则智能分类
3. 创建对应目录结构
4. 保存内容到正确位置
5. 建议后续动作

---

## 分诊方向（6大分类）

| 编号 | 分类 | 目录 | 内容类型 | 后续动作 |
|------|------|------|----------|----------|
| 01 | 内容生产 | `01-内容生产/` | 可发布的文章、推文素材 | 进入创作流程 |
| 02 | 项目 | `02-项目/` | 业务资料、项目文档 | 更新项目状态 |
| 03 | 学习 | `03-学习/` | 学习资料、读书笔记 | 制定学习计划 |
| 04 | 个人成长 | `04-个人成长/` | 思考、灵感、反思 | 定期回顾 |
| 05 | 稍后处理 | `05-稍后处理/` | 暂时无法分类 | 等待进一步指示 |
| 06 | 归档 | `06-归档/` | 无需处理的内容 | 直接存档 |

---

## 使用方法

### 基础分诊

```
你: /triage

AI: 请粘贴要分诊的内容（文章/想法/链接）

你: [粘贴内容]

AI: 📋 分诊结果
    ├─ 分类：01-内容生产/
    ├─ 评级：A类（高适配）
    ├─ 主题：AI 工作效率
    ├─ 存储位置：01-内容生产/01-素材库/2026-03-18-AI工作效率/
    └─ 建议：适合改写成长文

    已创建目录并保存。
    是否开始创作？（是/否/调整分类）
```

### 指定分类

```
你: 把这个放到学习资料里

AI: 已分诊到 03-学习/待整理/
    请确认学习主题。
```

### 批量分诊

```
你: 分诊这3篇文章
[文章1]
---
[文章2]
---
[文章3]

AI: 📋 批量分诊结果

    文章1：01-内容生产/（A类）
    文章2：03-学习/（学习资料）
    文章3：02-项目/（客户参考）

    是否确认？
```

## 分诊标准

### 01-内容生产（可发布）

**判断标准**：满足 2条+
- [ ] 可改写成文章/推文/视频
- [ ] 有传播价值
- [ ] 热点话题/观点/故事
- [ ] 目标读者明确
- [ ] 独特观点或信息

**子分类**：
- `01-素材库/` - 原始素材
- `02-待发布/` - 已完成内容
- `03-已发布/` - 已发布归档

**评级**：
- A类：高适配 → 立即创作
- B类：需调整 → 提供修改建议
- C类：放弃 → 说明原因

### 02-项目（业务/工作）

**判断标准**：
- 与具体项目相关
- 需要后续跟进
- 客户资料、会议纪要
- 交付物、文档

**子分类**：
- `{项目名称}/`
  - `文档/`
  - `会议纪要/`
  - `交付物/`

### 03-学习（知识输入）

**判断标准**：
- 学习资料/教程
- 读书笔记
- 需要深入研究
- 参考资料

**子分类**：
- `{主题}/`
  - `笔记/`
  - `资料/`
  - `总结/`

### 04-个人成长（思考沉淀）

**判断标准**：
- 个人思考/随想
- 灵感/创意
- 反思/复盘
- 目标规划

**子分类**：
- `随想/`
- `反思/`
- `规划/`

### 05-稍后处理（待决定）

**判断标准**：
- 暂时无法分类
- 需要更多信息
- 用户要求稍后处理

**处理**：定期回顾，决定最终去向

### 06-归档（无需处理）

**判断标准**：
- 已过期
- 纯参考（无需加工）
- 重复内容
- 临时信息

**处理**：直接存档，不进入工作流

---

## 扩展分诊方向

用户可以通过修改 `记忆库/强制规则/强制规则_内容分诊.md` 添加新的分诊方向。

**扩展方式**：
1. 添加新分类编号（07、08...）
2. 定义判断标准
3. 指定存储位置
4. 设置后续动作

---

## 注意事项

1. 所有分诊必须经过用户确认
2. 不确定时标记为"稍后处理"
3. 定期回顾"稍后处理"内容
4. 保留分诊历史记录
