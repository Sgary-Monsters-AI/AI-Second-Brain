# 强制规则：内容分诊

**优先级**：最高
**触发条件**：任何新输入（文章、想法、链接、文件）

---

## 分诊架构（可扩展）

当前支持 **6 大基础分类 + N 个扩展分类**

```
输入内容
    ↓
┌─────────────────────────────────────────┐
│           分诊决策引擎                    │
│  （基于关键词 + 内容分析 + 用户确认）       │
└─────────────────────────────────────────┘
    ↓
基础分类（01-06） 或  扩展分类（07+）
    ↓
创建目录 → 保存内容 → 建议后续动作
```

---

## 基础分类（6个）

### 01-内容生产 | `01-内容生产/`

**用途**：可发布的内容素材

**判断标准**（满足 2条+）：
- [ ] 可改写成文章/推文/视频
- [ ] 有传播价值
- [ ] 热点话题/观点/故事
- [ ] 目标读者明确
- [ ] 独特观点或信息

**存储结构**：
```
01-内容生产/
├── 01-素材库/           # 刚分诊的内容
│   └── {日期}-{标题}/
├── 02-待发布/           # 完成创作的内容
│   └── {日期}-{标题}/
│       ├── index.md
│       ├── wechat.md
│       └── ...
└── 03-已发布/           # 已发布的内容
    └── {日期}-{标题}/
```

**评级标准**：
| 评级 | 标准 | 动作 |
|------|------|------|
| A类 | 高适配、有价值、素材足 | 进入创作流程 |
| B类 | 有价值但需调整 | 提供修改建议 |
| C类 | 价值低或不适配 | 放弃，说明原因 |

**后续动作**：
- A类：启动内容生产引擎
- B类：提供修改建议，等待用户决策
- C类：移动到 06-归档/

---

### 02-项目 | `02-项目/`

**用途**：业务/工作项目相关资料

**判断标准**（满足 1条+）：
- [ ] 与具体项目相关
- [ ] 需要后续跟进
- [ ] 客户资料
- [ ] 会议纪要
- [ ] 交付物/文档

**存储结构**：
```
02-项目/
└── {项目名称}/
    ├── 📄 项目概要.md
    ├── 📁 会议纪要/
    ├── 📁 文档/
    ├── 📁 交付物/
    └── 📁 参考资料/
```

**后续动作**：
- 更新项目状态
- 创建相关任务
- 设置截止日期提醒

---

### 03-学习 | `03-学习/`

**用途**：学习资料、研究、知识积累

**判断标准**（满足 1条+）：
- [ ] 学习资料/教程
- [ ] 读书笔记
- [ ] 需要深入研究
- [ ] 参考资料
- [ ] 课程笔记

**存储结构**：
```
03-学习/
└── {主题}/
    ├── 📄 学习大纲.md
    ├── 📁 笔记/
    ├── 📁 资料/
    └── 📁 总结/
```

**后续动作**：
- 制定学习计划
- 创建知识卡片
- 关联已有知识

---

### 04-个人成长 | `04-个人成长/`

**用途**：个人思考、灵感、反思

**判断标准**（满足 1条+）：
- [ ] 个人思考/随想
- [ ] 灵感/创意
- [ ] 反思/复盘
- [ ] 情绪记录
- [ ] 目标规划

**存储结构**：
```
04-个人成长/
├── 📁 随想/
├── 📁 反思/
├── 📁 灵感/
├── 📁 规划/
└── 📄 年度目标.md
```

**后续动作**：
- 定期回顾
- 提炼方法论
- 转化为内容素材

---

### 05-稍后处理 | `05-稍后处理/`

**用途**：暂时无法分类，需要进一步判断

**判断标准**：
- [ ] 暂时无法确定分类
- [ ] 需要更多信息
- [ ] 用户明确要求稍后处理
- [ ] 分类模糊，需要讨论

**存储结构**：
```
05-稍后处理/
├── 📁 待分类/
│   └── {日期}-{临时标题}.md
└── 📄 待处理清单.md
```

**后续动作**：
- 定期回顾（建议每周一次）
- 与用户讨论确定分类
- 最终分配到其他分类或归档

---

### 06-归档 | `06-归档/`

**用途**：无需处理的内容，仅作存档

**判断标准**（满足 1条+）：
- [ ] 已过期
- [ ] 纯参考（无需加工）
- [ ] 重复内容
- [ ] 临时信息
- [ ] 已废弃

**存储结构**：
```
06-归档/
├── 📁 2026/
│   └── {日期}-{标题}.md
└── 📁 按主题/
```

**后续动作**：
- 直接存档
- 不进入工作流
- 定期清理（可选）

## 扩展分类（07+）

用户可以根据需要添加新的分诊方向。

### 如何添加新分类

**步骤 1：创建新目录**

```bash
mkdir ~/AI-Second-Brain/{编号}-{分类名称}
```

**步骤 2：编辑本规则文件**

在"扩展分类"区域添加：

```markdown
### {编号}-{分类名称} | `{编号}-{分类名称}/`

**用途**：描述用途

**判断标准**（满足 X条+）：
- [ ] 条件1
- [ ] 条件2
- [ ] 条件3

**存储结构**：
```
{编号}-{分类名称}/
└── ...
```

**后续动作**：
- 动作1
- 动作2
```

**步骤 3：更新启动流程**

在 `04-startup.md` 中添加新分类的说明。

**步骤 4：创建索引文件**

在新目录创建 `_index.md` 说明该分类的用途。

## 分诊流程

### 标准流程

```
输入内容
    ↓
分析内容特征
    ↓
匹配分类标准（遍历 01-06 + 扩展分类）
    ↓
推荐分类（可能多个）
    ↓
用户确认/调整
    ↓
创建目录结构
    ↓
保存内容
    ↓
建议后续动作
    ↓
更新任务清单（如需要）
```

### 分诊检查清单

每次分诊必须确认：

- [ ] 内容主题已理解
- [ ] 分类判断有依据
- [ ] 存储位置已确定
- [ ] 用户已确认
- [ ] 目录已创建
- [ ] 内容已保存
- [ ] 后续动作已建议
- [ ] 任务清单已更新（如需要）

## 分诊质量指标

### 准确性

- 分类正确率 > 90%
- 用户调整率 < 10%

### 效率

- 单次分诊时间 < 1 分钟
- 批量分诊支持 5-10 个同时处理

### 覆盖率

- 所有输入都有分类
- "稍后处理"占比 < 20%

## 分诊迭代机制

### 记录分诊历史

在 `记忆库/语义记忆/分诊历史.md` 记录：

```markdown
## 2026-03-18

### 分诊案例 1
- **输入**：AI 工作效率文章
- **初判**：01-内容生产/
- **用户调整**：无
- **结果**：✅ 正确

### 分诊案例 2
- **输入**：客户会议记录
- **初判**：02-项目/项目A
- **用户调整**：04-个人成长/反思
- **结果**：❌ 误判，更新规则
- **改进**：增加"会议记录默认进项目"规则
```

### 定期回顾

每月回顾：
- 分诊准确率统计
- 用户调整分析
- 规则优化建议

## 特殊情况处理

### 多分类匹配

当内容匹配多个分类时：

1. 列出所有可能分类
2. 说明每个分类的理由
3. 建议最优分类（基于用户近期行为）
4. 等待用户确认

### 无法判断

当无法确定分类时：

1. 标记为 05-稍后处理/
2. 记录判断困难的原因
3. 建议用户后续处理
4. 定期提醒回顾

### 分类变更

当内容需要变更分类时：

1. 确认新分类
2. 移动文件到正确位置
3. 更新链接（如有）
4. 记录变更原因
