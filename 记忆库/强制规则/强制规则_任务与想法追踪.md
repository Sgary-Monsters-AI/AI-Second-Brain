# 强制规则：任务与想法追踪

**优先级**：最高
**触发条件**：任何任务相关输入

---

## 任务捕捉规则

所有任务必须被捕捉并记录到 `任务清单.md`。

### 自动捕捉的信号

| 信号词 | 示例 | 动作 |
|--------|------|------|
| "我需要..." | "我需要整理这篇文章" | 创建任务 |
| "记得..." | "记得下周开会" | 创建任务 |
| "待办..." | "待办：修复 bug" | 创建任务 |
| "以后..." | "以后要学习这个" | 创建任务 |
| 日期/时间 | "周五前完成" | 创建任务+截止日期 |

---

## 任务格式

```markdown
### [ ] 任务标题
- **任务**：详细描述
- **优先级**：P0（紧急）/ P1（重要）/ P2（一般）
- **截止日期**：YYYY-MM-DD（可选）
- **来源**：从哪来（可选）
- **创建日期**：YYYY-MM-DD
```

---

## 优先级定义

- **P0**：紧急且重要，今天必须做
- **P1**：重要但不紧急，本周内做
- **P2**：一般任务，有时间再做

---

## 任务状态流转

```
[ ] 待办 → [~] 进行中 → [x] 已完成
            ↓
         [b] 阻塞（需说明原因）
```

## 任务清单结构

```markdown
# 📋 任务清单

## 🔴 紧急重要（P0）

### [ ] 示例任务
- **任务**：描述
- **优先级**：P0
- **截止日期**：YYYY-MM-DD

## 🟡 重要不紧急（P1）

### [ ] 示例任务
- **任务**：描述
- **优先级**：P1

## 🟢 一般任务（P2）

### [ ] 示例任务
- **任务**：描述
- **优先级**：P2

## ✅ 已完成

### [x] 示例任务
- **完成日期**：YYYY-MM-DD
```

---

## 每日简报

启动时必须输出：

1. **今日日期**
2. **紧急任务**（P0 且未过期）
3. **近期截止**（未来 7 天内截止的 P1 任务）
4. **已过期任务**（截止日期已过但未完成）
