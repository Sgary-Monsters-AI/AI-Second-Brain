# 内容生产系统

本目录存放所有与内容创作相关的资料、方法论和产出。

---

## 目录结构

```
01-内容生产/
├── _index.md                 # 本文件（索引）
├── 统一输出格式规范.md       # 内容输出标准
├── 方法论/                   # 写作方法、技巧、框架
│   ├── 内容筛选标准.md
│   ├── 文章结构模板.md
│   └── 平台适配指南.md
├── 01-素材库/               # 原始素材、参考资料
├── 02-待发布/               # 已完成、待发布的内容
└── 03-已发布/               # 已发布内容的归档
```

---

## 工作流程

```
素材/想法
    ↓
内容分诊 → 分类到素材库
    ↓
内容筛选 → A/B/C 评级
    ↓
内容创作 → 生成草稿
    ↓
质量评估 → 评分≥9.0?
    ↓
平台适配 → 生成多版本
    ↓
待发布 → 02-待发布/
    ↓
发布后 → 03-已发布/
```

## 快速开始

1. **有新想法？**
   - 直接告诉 AI："启动 AI 助手"
   - 说："今天有要分诊的内容"
   - 粘贴你的想法

2. **开始创作？**
   - 进入 `02-待发布/` 目录
   - 找到要创作的内容
   - 说："进入下一步"

3. **查看已完成？**
   - 查看 `02-待发布/` 目录
   - 所有内容按 `{日期}-{标题}/` 组织
