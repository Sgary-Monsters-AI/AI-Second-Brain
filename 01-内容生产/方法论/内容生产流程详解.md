# 内容生产流程详解

本文档详细说明内容创作的 13 步流程。

---

## 流程概览

```
Stage 1: 筛选（第0-1步）
    ↓
Stage 2: 创作（第2-6.5步）
    ↓
Stage 3: 保存（第7-9步）
    ↓
Stage 4: 输出（第10-13步）
```

---

## Stage 1: 筛选阶段

### 第0步：加载品牌配置

**目的**：确定内容风格和调性

**操作**：
- 读取 `记忆库/语义记忆/我的写作风格.md`
- 确定目标平台特点
- 明确内容类型（推文/长文/视频稿）

**检查点**：
- [ ] 品牌调性已明确
- [ ] 目标平台已确定
- [ ] 内容类型已确认

### 第1步：内容筛选

**目的**：判断是否值得投入时间创作

**评级标准**：

| 评级 | 标准 | 动作 |
|------|------|------|
| **A类** | 高适配、有价值、有素材 | 继续创作 |
| **B类** | 有价值但需调整 | 返回修改建议 |
| **C类** | 价值低或不适配 | 放弃，说明原因 |

**A类判断标准**（满足 2 条以上）：
- 符合品牌调性
- 目标读者明确
- 有独特观点或信息
- 有情绪价值或实用价值
- 素材充足

**阶段门检查**：
- 评级是否为 A 类？
- 是 → 进入 Stage 2
- 否 → 返回修改或放弃

---

## Stage 2: 创作阶段

### 第2步：战略定位

**目的**：明确内容的核心策略

**5W 框架**：

| 问题 | 说明 | 示例 |
|------|------|------|
| **Who** | 目标读者 | 25-35 岁职场人士 |
| **What** | 核心观点 | AI 可以提升 3 倍工作效率 |
| **Why** | 为什么重要 | 避免被 AI 取代 |
| **When** | 发布时机 | 随时，常青内容 |
| **Where** | 发布平台 | 公众号 + X |

**输出**：战略定位摘要（50 字以内）

### 第3步：草稿生成

**目的**：产出初稿

**格式要求**：
- 独白式（第一人称）
- 去 AI 味（避免"在当今时代"等套话）
- 3-5 个核心观点
- 每段 2-4 句话

**结构模板**：
```
开场（1 段）
    ↓
观点 1（2-3 段）
    ↓
观点 2（2-3 段）
    ↓
观点 3（2-3 段）
    ↓
结尾（1 段，CTA）
```

### 第4步：评估打分

**目的**：客观评估内容质量

**评分维度**（满分 10 分）：

| 维度 | 权重 | 说明 |
|------|------|------|
| 观点独特性 | 20% | 是否有新视角 |
| 信息价值 | 20% | 读者能获得什么 |
| 情绪张力 | 20% | 能否打动读者 |
| 逻辑清晰 | 20% | 结构是否合理 |
| 表达流畅 | 20% | 阅读体验如何 |

**评分标准**：
- 9.0-10：优秀，可直接发布
- 8.0-8.9：良好，小幅优化
- 7.0-7.9：合格，需要改进
- <7.0：不合格，重新创作

**阶段门检查**：
- 评分 ≥ 9.0？
- 是 → 进入下一步
- 否 → 返回第 3 步改进

### 第5步：RLHF 记录

**目的**：记录用户偏好，持续学习

**记录内容**：
```json
{
  "content": "文章标题",
  "changes": [
    {
      "before": "原标题",
      "after": "修改后标题",
      "reason": "用户反馈：原标题不够吸引人"
    }
  ],
  "preferences": [
    "偏好短句",
    "喜欢数据支撑"
  ]
}
```

### 第6步：章节优化

**目的**：优化长文结构

**触发条件**：字数 > 1000

**操作**：
- 添加小标题
- 划分章节
- 优化段落间距
- 添加过渡句

### 第6.5步：去 AI 味

**目的**：让内容更像人类写作

**检测项**：
- [ ] 避免"值得注意的是"
- [ ] 避免"在当今时代"
- [ ] 避免"不可否认的是"
- [ ] 避免过度总结（"综上所述"）
- [ ] 避免机械结构（首先/其次/最后）
- [ ] 增加个人语气和细节

**阶段门检查**：
- 去 AI 味已完成？
- 是 → 进入 Stage 3
- 否 → 返回修改

---

## Stage 3: 保存阶段

### 第7步：元文章保存

**目的**：保存完整内容到标准格式

**操作**：
- 创建目录：`{日期}-{标题}/`
- 创建 `index.md`
- 填充标准模板

**index.md 结构**：
```markdown
# 标题

**创建日期**：YYYY-MM-DD
**作者**：Name
**分类**：XXX
**标签**：#tag1 #tag2

---

## 元数据
- **目标读者**：XXX
- **核心观点**：XXX
- **预期效果**：XXX

---

## 正文
（完整内容）

---

## 版本记录
| 日期 | 版本 | 说明 |

---

## 平台适配
- [ ] 微信公众号
- [ ] X
- [ ] LinkedIn
```

### 第8步：提示词生成

**目的**：生成 AI 配图提示词

**输出**：`prompts.json`
```json
{
  "cover": "封面图提示词",
  "illustration_1": "插图1提示词",
  "illustration_2": "插图2提示词"
}
```

### 第9步：配图提示

**目的**：提醒用户生成图片

**操作**：
- 检查是否需要配图
- 提供提示词
- 建议图片风格

**阶段门检查**：
- 元文章已保存？
- prompts.json 已生成？
- 是 → 进入 Stage 4

---

## Stage 4: 输出阶段

### 第10步：选平台

**目的**：确定发布平台

**平台选项**：
- 微信公众号
- X (Twitter)
- LinkedIn
- 小红书
- 知乎
- 自建博客

### 第11步：生成版本

**目的**：生成各平台适配版本

**适配要点**：

| 平台 | 特点 | 适配方式 |
|------|------|----------|
| 微信公众号 | 长文友好 | 完整版 + 排版 |
| X | 短平快 | 拆分为多条 |
| LinkedIn | 专业感 | 强调商业价值 |
| 小红书 | 图文并茂 | 加 emoji，分点 |

### 第12步：预览与镜头检查

**目的**：确保内容服务读者

**镜头检查清单**：

| 检查项 | 标准 | 比例 |
|--------|------|------|
| 服务读者 | 读者获得价值 | >60% |
| 自我表达 | 作者表达观点 | <40% |
| 实用信息 | 可操作建议 | >50% |
| 情绪价值 | 打动人心 | >30% |

**检查方法**：
- 逐段检查：这段服务读者还是自我表达？
- 统计比例：读者服务占比多少？
- 优化调整：增加读者价值部分

### 第13步：传播素材

**目的**：准备发布所需的辅助材料

**输出清单**：
- [ ] 标题选项（3-5 个）
- [ ] 摘要/导语（50 字以内）
- [ ] 封面文案
- [ ] 标签/话题
- [ ] 发布时间建议

**生成文件**：`promotion.md`

---

## 流程完成

所有步骤完成后，内容包包含：

```
{日期}-{标题}/
├── index.md              # 元内容（必需）
├── wechat.md             # 公众号版本
├── x-cn.md               # X 中文（可选）
├── linkedin.md           # LinkedIn（可选）
├── xhs-long.md           # 小红书长文（可选）
├── promotion.md          # 传播素材
├── prompts.json          # 配图提示词
└── _attachments/         # 附件
```

---

## 效率优化

### 快速通道

- **短内容**（<500 字）：跳过章节优化
- **紧急发布**：简化评估，信任直觉
- **系列内容**：复用配置，批量处理

### 常用指令

| 指令 | 作用 |
|------|------|
| "开始创作" | 从第 0 步开始 |
| "进入下一步" | 继续下一环节 |
| "评估内容" | 跳转到第 4 步 |
| "生成公众号版本" | 跳转到第 11 步 |
