# 统一输出格式规范

**适用范围**：所有内容生产产出

---

## 文件夹命名规范

```
{YYYY-MM-DD}-{内容标题}/
```

**示例**：
- `2026-03-18-AI管理系统分享/`
- `2026-03-15-如何高效学习/`

---

## 文件清单

每个内容包必须包含：

### 必需文件

| 文件 | 说明 |
|------|------|
| `index.md` | 元内容/原始文案，包含完整内容和元数据 |
| `wechat.md` | 微信公众号版本（已排版） |

### 可选文件

| 文件 | 说明 |
|------|------|
| `x-cn.md` | X (Twitter) 中文版本 |
| `x-en.md` | X (Twitter) 英文版本 |
| `linkedin.md` | LinkedIn 版本 |
| `xhs-long.md` | 小红书长文版本 |
| `xhs-short.txt` | 小红书短文版本 |
| `video-transcript.md` | 视频逐字稿 |
| `promotion.md` | 传播素材（标题/摘要/封面文案） |
| `prompts.json` | AI 配图生成提示词 |
| `_attachments/` | 附件目录（图片、PDF 等） |

---

## index.md 模板

```markdown
# 内容标题

**创建日期**：YYYY-MM-DD
**作者**：Your Name
**分类**：内容分类
**标签**：#标签1 #标签2

---

## 元数据

- **目标读者**：描述目标受众
- **核心观点**：一句话总结
- **预期效果**：读者读完会获得什么

---

## 正文

（完整文章内容）

---

## 版本记录

| 日期 | 版本 | 说明 |
|------|------|------|
| YYYY-MM-DD | v1.0 | 初稿 |

---

## 平台适配

- [x] 微信公众号
- [ ] X (Twitter)
- [ ] LinkedIn
- [ ] 小红书
```

---

## 版本控制

所有内容使用 Git 管理：

```bash
# 提交内容
git add 01-内容生产/02-待发布/2026-03-18-xxx/
git commit -m "content: 添加文章《xxx》"
```
